# 本をテンプレートページへ移す

<strong>ページのテキストをスタイルに入れている本も、そのテキストをMarkdownへ移せば、編集も翻訳もできるようになります。</strong>

テンプレートページができる前は、教科書をPostextへ移すとき、各ページを隠れた見出しとして作ることがよくありました。その見出しの柱が、印刷されたページと同じ位置にテキスト、箱、画像を置いていたのです。ページの見た目は正しくても、言葉は設定の中にあります。そのため、誤字を1つ直すにもスタイルを開く必要があり、翻訳するにはスタイルをコピーするしかありませんでした。テンプレートページは同じことを、形は<strong>ページテンプレート</strong>、言葉はMarkdownと分けて行います。詳しくは[テンプレートページで作る本](/ja/docs/composed-page-books)にあります。このページでは、古い形の本をその形へ移します。

古い形の本かどうかは、<strong>検査</strong>パネルで分かります。文章が入った見出しスタイルごとに*設定内に置かれた本文*（`contentInConfig`）が1件ずつ並び、一覧の先頭に<strong>テキストをMarkdownへ移す</strong>が出ます。

## 練習用の本

以下の手順では、このページのために作った小さな本、<em>Our World, before composed pages</em>を使います。3年生（Year 3）向けの教科書の3ページ分です。各ページは1つの見出しスタイルで、その柱が画像、カード、タイトル、3つのテキストブロックを置いています。1つの語の下には黄色い帯が引かれています。文章も画像も架空のものです。[本をダウンロード](/docs-examples/our-world-before.postext)し、Sandboxで<strong>本</strong>を開いて<strong>新規</strong>を押し、<strong>.postextファイルを開く…</strong>を選びます。

## アシスタントで移す

スタイルにテキストが入った本を読み込むと、<strong>テキストをMarkdownへ移す</strong>のダイアログが自動で開きます。閉じてしまった場合や、本がすでに一覧にある場合は、<strong>検査</strong>を開いて一覧の先頭のボタンを押します。<strong>テキストを移す</strong>を押すまで、何も変わりません。

1. <strong>変わること</strong>を読みます。練習用の本では、16個のテキスト（567文字）が移り、3つのテンプレートページが書かれ、3つの見出しスタイルが1つになり、3つのハイライトの箱がチップになり、<em>設定内に置かれた本文</em>の警告が3件から0件になる、と出ます。
2. オプションを見ます。<strong>同じ位置に枠があるページはテンプレートを共有する</strong>は、同じ作りのページに共通のベーステンプレートを1つ用意し、ほかのページがそれを拡張するようにします。<strong>太字の下のハイライトの箱をチップにする</strong>は、太字の下に描かれた色付きの箱を、本のチップスタイルのチップにします。<strong>画像の上の語をその画像のラベルにする</strong>は、古いデザインが画像の上に短い語（地図の地名など）を置いているときに出ます。その語は、画像のアンカーに置く`::label`の行になります。この変換でいちばん大きく変わるのはこれらのページなので、自分でオンにするまではオフのままです。
3. <strong>移す前と後</strong>では、Sandboxが各章を2回組み、変わるページをすべて、古いページと新しいページを並べて表示します。リストには、見た目が変わるページと、分かる場合はその理由が出ます。<strong>変わった部分を赤で示す</strong>は、違いのあるピクセルを赤く塗ります。練習用の本では、3ページすべてに*見た目は同じ*と出ます。
4. <strong>テキストを移す</strong>を押します。

移す操作は、書き換えた章ごとに1手、デザインに1手として本の履歴に記録されます。ダイアログの<strong>元に戻す</strong>は、ほかに何も変わっていなければ、すべてを元に戻します。<strong>Cmd/Ctrl+Z</strong>なら1手ずつ戻せます。移す前の本も、検査パネルで<strong>変更を確定する</strong>を押すまで保存されていて、それまでは<strong>本を元の状態に戻す</strong>で、古いデザインと本文を書き戻せます。

## 移したあとに確かめること

<strong>本文</strong>パネルを開きます。章には、ページごとに1つのブロックが入っています。

```md
::::page{template="page-base" background="art-p1"}
# Rivers and seas {style="topic" id="t-rivers"}

:::frame{slot="shared-2"}
:::paragraphs{style="fredoka-30-center-ffffff"}
Rivers and seas
:::
:::
...
::::
```

結果は、次の順で見ていきます。

- <strong>見た目が変わったページ。</strong> ダイアログのリストには、分かる範囲の理由が出ていました。テキスト自身の箱、輪郭線、ドロップキャップ、左右が分からなかったページ、テンプレートの流し込み枠で組まれるようになった本文などです。そうしたページをCanvasで見比べます。
- <strong>テンプレート。</strong> <strong>デザイン › ページと段組み › ページテンプレート</strong>には、ページのデザインごとに1つのテンプレートと、ページが共有する枠のための`page-base`が並びます。何も足さないページはベースをそのまま使い、それ以外のページはベースを拡張します。名前は古い名前から作られているので、分かりやすい名前に変えてください（テンプレートの名前を変えると、それを指定しているすべてのページで変わります）。
- <strong>段落スタイル。</strong> 各テキストの書体、サイズ、ウェイト、色、そろえ、行送りは段落スタイルになりました。完全に一致する本のスタイルがあればそれを使い、なければ書体とサイズから名前を付けた新しいスタイル（`nunito-11`）が作られます。<strong>デザイン › 文字組み › 段落スタイル</strong>を開いて、新しいスタイルの名前を変えるか、まとめます。
- <strong>見出し。</strong> 同じになった見出しスタイルはまとめられ、見出しの名前も書き換わりました。柱を切り替えるだけの隠れた見出しはなくなりました。本に目次のページがあれば、そこも確かめます。
- <strong>設定に残るもの。</strong> ダイアログの<strong>設定に残るもの</strong>のリストには、言葉とプレースホルダーが混ざったテキスト（`Page {pageNumber}`）、別の要素に付いたテキスト、見出しのデザインのテキストが挙がっています。これらはページの内容ではなく、残っている*設定内に置かれた本文*の警告は、これらについてのものです。
- <strong>ラベル。</strong> <em>画像の上の語をその画像のラベルにする</em>をオンにした場合は、地図や図解を1つずつ見ます。ラベルは本のフォントで組み直されるので、大きさや位置が古いページと違うことがあります。
- <strong>検査パネル。</strong> テキストが収まらなくなった枠は、<em>枠に収まらないテキスト</em>として出ます。直し方は[テンプレートページで作る本](/ja/docs/composed-page-books#6-収まらないものを直す)にあります。印刷されたページを写して作った本は枠にぎりぎりで収まっているので、少しでも長くなるテキストがあれば、すぐに直しが必要になります。

納得できたら、<strong>変更を確定する</strong>を押します。これで、この本はほかのテンプレートページの本と同じように翻訳できます。

## 手作業で移す

ページ数の少ない本なら、アシスタントを使わずに、1ページずつ移せます。

1. <strong>デザイン</strong>モードでページテンプレートを作ります。本のテンプレートページの上にテキストごとの枠を描くか、[テンプレートページで作る本](/ja/docs/composed-page-books#2-ページテンプレートを作る)の手順に従います。各枠には、見た目を決める囲みスタイルを付け、古いテキストの高さを<strong>最小の高さ</strong>に入れます。
2. <strong>内容</strong>モードで、ページを`::::page{template="…"}`のブロックとして書き、古い柱のテキストを1つずつ、新しいブロックの`:::frame{slot="…"}`に移します。太字とイタリックは残し、古いテキストの改行は、行末のバックスラッシュで残します。
3. 見出しスタイルからテキストの要素を削除します。ほかに使わないなら、見出しスタイルごと削除します。そのスタイルの*設定内に置かれた本文*の警告は消えます。
4. ページを古いものと見比べて、<strong>検査</strong>を開きます。

同じ移行はコードからも使えます。`moveTextToMarkdown`が、新しい設定、章、ダイアログが示すレポートを返します。[テンプレートページ › テキストをスタイルに置いた本の移行](/ja/docs/composed-pages#テキストをスタイルに置いた本の移行)を参照してください。ダイアログが行うことはすべて、[Sandbox：テンプレートページ › テキストをMarkdownへ移す](/ja/docs/sandbox-composed-pages#テキストをmarkdownへ移す)に書かれています。
