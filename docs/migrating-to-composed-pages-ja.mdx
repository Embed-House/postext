# 本をテンプレートページへ移す

<strong>ページのテキストをスタイルの中に持っている本は、そのテキストをMarkdownへ移すと、編集も翻訳もできるようになります。</strong>

テンプレートページができる前は、教科書をPostextへ移すとき、各ページを隠れた見出しとして作り、その柱が、印刷されたページと同じ位置にテキスト、箱、絵を置くことがよくありました。ページの見た目は正しくても、言葉は設定の中にあるので、誤字を直すにはスタイルを開く必要があり、翻訳にはスタイルのコピーが必要でした。テンプレートページは、同じ仕事を、形は<strong>ページテンプレート</strong>に、言葉はMarkdownに分けて行います。詳しくは[テンプレートページで作る本](/ja/docs/composed-page-books)にあります。このページでは、古い形の本をその形へ移します。

古い形の本かどうかは、<strong>検査</strong>パネルで分かります。文章を持つ見出しスタイルごとに*設定内に置かれた本文*（`contentInConfig`）が一つずつ並び、一覧の先頭に<strong>テキストをMarkdownへ移す</strong>が出ます。

## 練習用の本

以下の手順では、このページのために作った小さな本、<em>Our World, before composed pages</em>を使います。Year 3 向けの教科書の3ページ分で、各ページは見出しスタイルと柱でできています。柱が、絵、カード、見出し、三つのテキストを置き、一つの語の下には黄色い帯が付いています。言葉も絵も架空のものです。[本をダウンロード](/docs-examples/our-world-before.postext)し、Sandboxで<strong>本</strong>を開いて<strong>新規</strong>を押し、<strong>.postextファイルを開く…</strong>を選びます。

## アシスタントで移す

スタイルにテキストを持つ本を読み込むと、<strong>テキストをMarkdownへ移す</strong>のダイアログが自動で開きます。閉じてしまった場合や、本がすでに一覧にある場合は、<strong>検査</strong>を開いて一覧の先頭のボタンを押します。<strong>テキストを移す</strong>を押すまで、何も変わりません。

1. <strong>変わること</strong>を読みます。練習用の本では、16個のテキスト（567文字）が移り、3つのテンプレートページが書かれ、3つの見出しスタイルが1つになり、3つのハイライトの箱がチップになり、<em>設定内に置かれた本文</em>の警告が3件から0件になる、と出ます。
2. オプションを見ます。<strong>同じ位置に枠があるページはテンプレートを共有する</strong>は、同じ作りのページに共通のベーステンプレートを一つ持たせ、各ページがそれを拡張するようにします。<strong>太字の下のハイライトの箱をチップにする</strong>は、太字の下に描かれた色付きの箱を、本のチップスタイルのチップにします。<strong>画像の上の語をその画像のラベルにする</strong>は、古いデザインが絵の上に短い語（地図の地名など）を置いているときに出ます。その語は、絵のアンカーの位置にある `::label` の行になります。いちばん変わるページが出るので、最初はオフになっています。
3. <strong>移す前と後</strong>では、Sandboxが各章を2回組み、変わるページを古いものと新しいものを並べて描きます。リストには、どのページの見た目が変わるかと、分かる場合はその理由が出ます。<strong>変わった部分を赤で示す</strong>は、違うピクセルを塗ります。練習用の本では、3ページすべてに*見た目は同じ*と出ます。
4. <strong>テキストを移す</strong>を押します。

移す操作は、本の履歴の1手として記録されます。書き換えた章ごとに1手、デザインに1手です。ダイアログの<strong>元に戻す</strong>は、ほかに何も変わっていなければ、すべてを元に戻します。<strong>Cmd/Ctrl+Z</strong>なら1手ずつ戻せます。移す前の本も、検査パネルで<strong>変更を確定する</strong>を押すまで保存されていて、それまでは<strong>本を元の状態に戻す</strong>で、古いデザインと本文を書き戻せます。

## 移したあとに確かめること

<strong>本文</strong>パネルを開きます。章には、ページごとに一つのブロックが入っています。

```md
::::page{template="page-base" background="art-p1"}
# Rivers and seas {style="topic" id="t-rivers"}

:::frame{slot="shared-2"}
:::paragraphs{style="fredoka-30-center-ffffff"}
Rivers and seas
:::
:::
...
::::
```

結果は、次の順で見ていきます。

- <strong>見た目が変わったページ。</strong> ダイアログのリストには、分かる範囲の理由が出ていました。テキスト自身の箱、輪郭線、ドロップキャップ、左右が分からなかったページ、テンプレートの流し込み枠で組まれるようになった本文などです。そうしたページをキャンバスで見比べます。
- <strong>テンプレート。</strong> <strong>デザイン › ページと段組み › ページテンプレート</strong>には、ページのデザインごとに一つのテンプレートと、ページが共有する枠のための `page-base` が並びます。何も足さないページはベースをそのまま使い、それ以外のページはベースを拡張します。名前は古い名前から作られているので、分かりやすい名前に変えてください（テンプレートの名前を変えると、それを指定しているすべてのページで変わります）。
- <strong>段落スタイル。</strong> 各テキストの書体、サイズ、ウェイト、色、揃え、行送りは段落スタイルになりました。完全に一致する本のスタイルがあればそれを使い、なければ書体とサイズから名前を付けた新しいスタイル（`nunito-11`）が作られます。<strong>デザイン › 本文</strong>を開いて、新しいスタイルの名前を変えるか、まとめます。
- <strong>見出し。</strong> 同じになった見出しスタイルはまとめられ、見出しの名前も書き換わりました。柱を切り替えるだけの隠れた見出しはなくなりました。本に目次のページがあれば、そこも確かめます。
- <strong>設定に残るもの。</strong> ダイアログの<strong>設定に残るもの</strong>のリストには、言葉とプレースホルダーが混ざったテキスト（`Page {pageNumber}`）、別の要素に付いたテキスト、見出しのデザインのテキストが挙がっています。これらはページの内容ではなく、残っている*設定内に置かれた本文*の警告は、これらについてのものです。
- <strong>ラベル。</strong> <em>画像の上の語をその画像のラベルにする</em>をオンにした場合は、地図や図解を一つずつ見ます。ラベルは本のフォントで組み直されるので、大きさや位置が古いページと違うことがあります。
- <strong>検査パネル。</strong> テキストが収まらなくなった枠は、<em>枠に収まらないテキスト</em>として出ます。直し方は[テンプレートページで作る本](/ja/docs/composed-page-books#6-収まらないものを直す)にあります。印刷されたページから作った本は余裕がなく、少し長い言葉が来ると直しが要ります。

納得できたら、<strong>変更を確定する</strong>を押します。これで、この本はほかのテンプレートページの本と同じように翻訳できます。

## 手作業で移す

ページ数の少ない本なら、アシスタントを使わずに、1ページずつ移せます。

1. デザインモードでページテンプレートを作ります。本のテンプレートページの上にテキストごとの枠を描くか、[テンプレートページで作る本](/ja/docs/composed-page-books#2-ページテンプレートを作る)の手順に従います。各枠には、見た目を決める囲みのスタイルを付け、古いテキストの高さを<strong>最小の高さ</strong>に入れます。
2. 内容モードで、ページを `::::page{template="…"}` のブロックとして書き、古い柱のテキストを一つずつ、新しいブロックの `:::frame{slot="…"}` に移します。太字と斜体は残し、古いテキストの改行は、行末のバックスラッシュで残します。
3. 見出しスタイルからテキストの要素を削除します。ほかに使わないなら、見出しスタイルごと削除します。そのスタイルの*設定内に置かれた本文*の警告は消えます。
4. ページを古いものと見比べて、<strong>検査</strong>を開きます。

同じ移行はコードからも使えます。`moveTextToMarkdown` が、新しい設定、章、ダイアログが示すレポートを返します。[テンプレートページ › スタイルにテキストを持つ本の移行](/ja/docs/composed-pages#スタイルにテキストを持つ本の移行)を参照してください。ダイアログが行うことはすべて、[Sandbox：テンプレートページ › テキストをMarkdownへ移す](/ja/docs/sandbox-composed-pages#テキストをmarkdownへ移す)に書かれています。
