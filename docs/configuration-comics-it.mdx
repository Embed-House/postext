# Configurazione: fumetti


## Fumetti

La proprietà `comics` configura le tavole a fumetti (`:::page`), le strisce (`:::strip`) e le doppie pagine: la cornice e gli spazi da cui si ritagliano le vignette, gli stili delle vignette, il lettering, gli stili delle nuvolette e i personaggi. La leggono solo i documenti che contengono fumetti; un documento senza fumetti si impagina esattamente come prima, e un documento con fumetti ma senza una sezione `comics` prende i valori predefiniti della sua lingua. Il markup e il modo in cui si letterano le tavole sono spiegati in [Fumetti](/it/docs/comics).

```ts
const config: PostextConfig = {
  comics: {
    readingDirection: 'auto',
    gutter: { horizontal: { value: 5, unit: 'mm' }, vertical: { value: 2.5, unit: 'mm' } },
    panel: { borderWidth: { value: 0.8, unit: 'pt' }, borderStyle: 'rough' },
    panelStyles: [{ id: 'night', background: { hex: '#14142b', model: 'hex' }, borderColor: { hex: '#ffffff', model: 'hex' } }],
    lettering: { fontSize: { value: 8.5, unit: 'pt' }, textTransform: 'uppercase' },
    balloonStyles: [{ id: 'eerie', shape: 'wavy', italic: true }],
    cast: [{ id: 'maya', name: 'Maya' }, { id: 'tomas', name: 'Grandpa Tomás' }],
  },
};
```

### Stili delle nuvolette

Ogni voce di `comics.balloonStyles` si sovrappone allo stile predefinito con lo stesso id (`speech`, `thought`, `whisper`, `shout`, `radio`, `caption`, `inner`, `note`, `sfx`), oppure a `speech` per un id nuovo. I valori predefiniti qui sotto sono quelli di `speech`; la [pagina Fumetti](/it/docs/comics#stili-delle-nuvolette) elenca che cosa cambia ogni stile predefinito. Le lunghezze in `em` sono relative alla dimensione del testo della nuvoletta.

const resolved = resolveComicsConfig(config.comics, 'ja');

const night = pickPanelStyle(resolved, 'night');   // a named panel style, else the default panel
