# Konfiguration: Comics


## Comics

Die Eigenschaft `comics` konfiguriert Comicseiten (`:::page`), Strips (`:::strip`) und Doppelseiten: den Rahmen der Comicseite (die Fläche innerhalb der Ränder) und die Zwischenräume, aus denen die Panels geschnitten werden, die Panelstile, das Lettering, die Sprechblasenstile und die Figurenliste. Nur Dokumente mit Comics lesen sie; ein Dokument ohne Comics wird genau wie zuvor gesetzt, und ein Dokument mit Comics und ohne Abschnitt `comics` übernimmt die Standardwerte seiner Sprache. Die Auszeichnung und die Art, wie Seiten gelettert werden, erklärt [Comics](/de/docs/comics).

```ts
const config: PostextConfig = {
  comics: {
    readingDirection: 'auto',
    gutter: { horizontal: { value: 5, unit: 'mm' }, vertical: { value: 2.5, unit: 'mm' } },
    panel: { borderWidth: { value: 0.8, unit: 'pt' }, borderStyle: 'rough' },
    panelStyles: [{ id: 'night', background: { hex: '#14142b', model: 'hex' }, borderColor: { hex: '#ffffff', model: 'hex' } }],
    lettering: { fontSize: { value: 8.5, unit: 'pt' }, textTransform: 'uppercase' },
    balloonStyles: [{ id: 'eerie', shape: 'wavy', italic: true }],
    cast: [{ id: 'maya', name: 'Maya' }, { id: 'tomas', name: 'Grandpa Tomás' }],
  },
};
```

`comics.lettering` legt jede Sprechblase des Buchs fest. Es gibt eine einzige Größe: Ein Sprechblasenstil kann sie skalieren (`fontScale`), und Text wird nie verkleinert, damit er in eine Sprechblase passt.

### Sprechblasenstile

Jeder Eintrag von `comics.balloonStyles` wird über den eingebauten Stil mit derselben ID gelegt (`speech`, `thought`, `whisper`, `shout`, `radio`, `caption`, `inner`, `note`, `sfx`) oder bei einer neuen ID über `speech`. Die Standardwerte unten sind die von `speech`; die [Seite Comics](/de/docs/comics#sprechblasenstile) führt auf, was jeder eingebaute Stil ändert. Längen in `em` beziehen sich auf die Textgröße der Sprechblase.
