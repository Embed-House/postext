# Configuration : bande dessinée


## Bande dessinée

La propriété `comics` configure les planches (`:::page`), les strips (`:::strip`) et les doubles pages : le cadre et les gouttières dans lesquels les cases sont découpées, les styles de case, le lettrage, les styles de bulles et les personnages. Seuls les documents qui contiennent de la bande dessinée en tiennent compte ; un document sans BD se compose exactement comme avant, et un document avec BD mais sans section `comics` prend les valeurs par défaut de sa langue. Le balisage et la façon dont les planches sont lettrées sont expliqués dans [Bande dessinée](/fr/docs/comics).

```ts
const config: PostextConfig = {
  comics: {
    readingDirection: 'auto',
    gutter: { horizontal: { value: 5, unit: 'mm' }, vertical: { value: 2.5, unit: 'mm' } },
    panel: { borderWidth: { value: 0.8, unit: 'pt' }, borderStyle: 'rough' },
    panelStyles: [{ id: 'night', background: { hex: '#14142b', model: 'hex' }, borderColor: { hex: '#ffffff', model: 'hex' } }],
    lettering: { fontSize: { value: 8.5, unit: 'pt' }, textTransform: 'uppercase' },
    balloonStyles: [{ id: 'eerie', shape: 'wavy', italic: true }],
    cast: [{ id: 'maya', name: 'Maya' }, { id: 'tomas', name: 'Grandpa Tomás' }],
  },
};
```

### Lettrage

`comics.lettering` règle toutes les bulles du livre. Il n’y a qu’un seul corps : un style de bulle peut le mettre à l’échelle (`fontScale`), et le texte n’est jamais réduit pour tenir dans une bulle.

### Styles de bulles

Chaque entrée de `comics.balloonStyles` s’applique par-dessus le style prédéfini de même identifiant (`speech`, `thought`, `whisper`, `shout`, `radio`, `caption`, `inner`, `note`, `sfx`), ou par-dessus `speech` pour un nouvel identifiant. Les valeurs par défaut ci-dessous sont celles de `speech` ; la [page Bande dessinée](/fr/docs/comics#styles-de-bulles) indique ce que change chaque style prédéfini. Les longueurs en `em` sont relatives au corps du texte de la bulle.

      <td>Rotation en degrés, dans le sens des aiguilles d’une montre. L’attribut <code>rotate</code> d’une ligne l’emporte.</td>
    </tr>
    <tr>

      <td><code>number</code></td>

Chaque entrée de `comics.cast` décrit un personnage :

La `color` et la `font` propres à une ligne l’emportent sur la distribution, et la distribution sur le style de bulle. Toute couleur de BD peut être une entrée de la palette, qui suit alors la palette comme n’importe quelle couleur liée.

```ts
const resolved = resolveComicsConfig(config.comics, 'ja');
// => every field filled; Zen Antique and Dela Gothic One as the faces

const minimal = stripComicsDefaults(config.comics, 'ja');
// => undefined when everything is a default

const shout = pickBalloonStyle(resolved, 'shout'); // the built-in shout with the book's changes
const night = pickPanelStyle(resolved, 'night');   // a named panel style, else the default panel
```
