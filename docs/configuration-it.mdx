# Configurazione

**In Postext ogni decisione di impaginazione dipende da un unico oggetto di configurazione.**

`PostextConfig` regola le dimensioni della pagina, la disposizione delle colonne, la tipografia del testo corrente, gli stili dei titoli, la lingua del documento (`locale`) e altro ancora. Ogni proprietà è facoltativa: Postext parte da valori predefiniti ragionevoli, ispirati alla tipografia tradizionale del libro. Devi indicare soltanto ciò che vuoi cambiare.

```ts
import { buildDocument } from 'postext';

const document = buildDocument(content, {
  page: { sizePreset: '21x28', dpi: 300 },
  layout: { layoutType: 'double', gutterWidth: { value: 0.5, unit: 'cm' } },
  bodyText: { fontFamily: 'EB Garamond', fontSize: { value: 9, unit: 'pt' } }, // 9 pt overrides the 8 pt default
  headings: { fontFamily: 'Open Sans' },
});
```

Per una panoramica di come il motore elabora questa configurazione, consulta la pagina [Architettura](/it/docs/architecture).
