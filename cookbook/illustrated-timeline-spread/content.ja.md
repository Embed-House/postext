# 紙がたどった道

紙をすく技術は、長いあいだ中国の工房の秘密でした。そこからヨーロッパの水車小屋に届くまで、千年以上の時間がかかっています。

技術を受け取った土地の人びとは、身近な材料に合わせて作り方を変えました。中国ではクワの樹皮、日本では楮（こうぞ）、サマルカンドやアンダルスでは亜麻とぼろ布、そして19世紀には木材です。

:::frame{slot="box" label="手すき紙ができるまで"}
1. 繊維を細かくして水につけ、どろどろの紙料にする。
2. 木の枠に細かい網を張ったすき枠を漉き舟に入れ、紙料をすくい上げる。
3. すき枠をゆすると水が落ち、繊維がからみ合って均一な層になる。
4. フェルトにはさんで圧搾し、つるして乾かす。

すき枠の網の跡は紙に残ります。紙を光にかざすと見える細い線がそれです。
:::

**中国**　後漢の宦官、{蔡倫|さいりん}が、樹皮や麻くず、ぼろ布、古い漁網から作った紙を皇帝に献上します。絹より安く、竹簡よりずっと軽い書写材料でした。これより200年ほど古い紙も見つかっていますが、帝国じゅうに広まったのは蔡倫の紙です。
:::

:::frame{slot="asia" label="610年"}
::resource{id="v610"}

**日本**　『日本書紀』によると、高句麗の僧、{曇徴|どんちょう}が紙と墨の作り方を伝えました。やがて楮の皮から、薄くて丈夫な和紙がすかれるようになります。奈良の正倉院には、702年の紙に書かれた戸籍が今も残っています。
:::

:::frame{slot="asia" label="751年"}
::resource{id="v751"}

**サマルカンド**　タラス河畔の戦いで捕らえられた中国人が、このシルクロードの町に紙すきを伝えたという言い伝えがあります。原料は亜麻と木綿のぼろ布でした。800年ごろにはバグダードにも工房ができ、カリフの役所では紙が羊皮紙に代わります。
:::

:::frame{slot="europe" label="1150年"}
::resource{id="v1150"}

**シャティバ**　地理学者イドリースィーは、アンダルスのこの町で作られる紙は世界に並ぶものがなく、東へも西へも売られていると書いています。1244年にアラゴン王ハイメ1世が町を征服したあとも、工房は仕事を続けました。
:::

:::frame{slot="europe" label="1282年"}
::resource{id="v1282"}

**ファブリアーノ**　イタリアのこの町の製紙場では、川の水車が木づちを動かし、ぼろ布をつき砕きました。インクがにじまないよう紙にゼラチンを引き、光にかざすと見える透かし模様を入れます。14世紀には、イタリアの紙がヨーロッパの半分で売られていました。
:::

:::frame{slot="europe" label="1844年"}
::resource{id="v1844"}

**ザクセン**　印刷術のあとに新聞が生まれ、ぼろ布だけでは紙が足りなくなります。1798年、フランスのルイ＝ニコラ・ロベールが、すき枠を使わずに長い紙を連続して作る機械を組み立てていました。1844年、織工のフリードリヒ・ゴットロープ・ケラーは、トウヒの丸太を砥石に押し当ててパルプを作ります。こうして紙は安く大量に作れるようになり、新聞1部の値段はパン1個ほどになりました。
:::
