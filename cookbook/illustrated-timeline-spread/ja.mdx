## できあがり

中学校の歴史の教科書の48・49ページ、「紙がたどった道」です。蔡倫の工房からケラーの砥石まで、紙すきの千年をたどります。左ページは題名と二つの段落で始まり、右ページは手すき紙の作り方を説明する囲みで始まります。真ん中を年表が横切ります。アジアは藍色の帯、ヨーロッパは赤茶の帯で、赤茶の帯は左ページから始まってのどをまたぎます。その下に、絵の付いたカードが六枚、点と線で帯からつり下がっています。カードは幅を分け合います。いちばん話の長い1844年のカードが両隣から幅を借り（スペイン語版で1mm、日本語版で7mm）、その点もいっしょに動きます。文字はすべてMarkdownにあり、スペイン語、英語、日本語の三版があります。このページは日本語版です。

## 作り方

### 1 · 二ページで一枚のシート

<Excerpt region="answer" />

`spread: true`でテンプレートは二ページ分の幅の一枚のシートになり、ページのブロックも`spread`で同じことを示します。見開きは左ページから始まるので、ビルドに`continuation: { pageIndexOffset: 1, pageNumbering: { startAt: 48 } }`を渡します。この抜粋の1ページ目は本の48ページ、左ページになり、前に白ページは入りません。グリッドは一ページに一列で、列の間はノド側の余白の二倍です。のどに近づくのは帯だけです。二本目の帯は`crossGutter`と左の36mmの余白を持ちます。色は一本目の帯の端から続いてのどをまたぎ、文字は右ページから始まります。文字が読まれるのも右ページです。

### 2 · 幅を分け合うカード

<Excerpt region="cards" />

三枚のカードの列はそれぞれ`row`グループで、カードには描いたときの高さの`minHeight`があり、それより上は`auto`の高さです。カードの文章が列の高さに収まらないと、`shrink`を持つ隣のカードから必要な最小のミリ数を借ります。隣のカードは、自分の文章が収まる幅を残します。借りきれないときにだけ列が下へ伸びます。1844年のカードは、スペイン語版では1282年のカードから1mm、日本語版では1150年から3mm、1282年から4mm、合わせて7mm借ります。すべての文章を30%長くしたベンチのテストでは、日本語版は両隣から合わせて18mm借り、1150年と1282年のカードの絵も85%に縮み、囲みとリードの文字は87.5%と82.5%になります。

### 3 · カードに付いて動く点

<Excerpt region="marks" />

点と線はテンプレートの飾り（`decoration`）で、`#c1` … `#c6`の上端（`top`）に固定し、帯までの距離だけ上にずらしています。飾りは枠を置いたあとに配置されるので、カードが動いたり広がったりしても、点はいつもカードの中央の上にあります。クリーム色の地も飾りで、裁ち落としの下端に固定した箱です。高さは`#band-1`の下端まで届くので（`size: { height: { to: '#band-1', edge: 'bottom' } }`）、帯に付いて動きます。

### 4 · 印刷の大きさで置く絵

<Excerpt region="art" />

挿絵は幅1,000px、550ppiで、ページ上では46mmです。画像は拡大されないので、広がったカードは絵の大きさを保ち、増えた幅を文章に回します。53mm（絵に左右3.5mmずつの余白を足した幅）より狭いカードでは絵が縮みます。ベンチのテストの日本語版では、1150年と1282年のカードの絵が85%になります。

## アレンジ

### カードの幅をそろえる

`shrink: 0`にすると、どのカードも幅を譲りません。代わりに列が下へ伸び、三枚が一緒に高くなって、列の下端がページの下へずれます。

```diff
-  shrink: 1, // a card gives width to a neighbour whose text runs past the row
+  shrink: 0,
```

## よくあるつまずき

- 固定の`height`を持つカードは幅の貸し借りに加わりません。列からはみ出すことがないからです。ここでのようにカードには`minHeight`を与え、高さは`auto`のままにします。
- 別の箱の端まで届く大きさは、要素自身の固定点から数えます。クリーム色の地は裁ち落としの下端に固定し、上へ`#band-1`まで伸びます。固定点の後ろにある端は、高さ0になります。
