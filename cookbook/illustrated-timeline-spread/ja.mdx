## できあがり

中学校の歴史の教科書の48・49ページ、「紙がたどった道」です。蔡倫の工房からケラーの砥石まで、紙すきの千年をたどります。左ページは題名と二つの段落で始まり、右ページは手すき紙の作り方を説明する囲みで始まります。真ん中を年表が横切ります。アジアは藍色の帯、ヨーロッパは赤茶の帯で、赤茶の帯は左ページから始まってのどをまたぎます。その下に、画像の付いたカードが六枚、輪と線で帯からつり下がっています。テンプレートにあるのは、アジアのカード一枚、ヨーロッパのカード一枚、帯ごとのコネクタ一本だけです。グリッドがMarkdownの日付ごとにカードを置き、コネクタはグリッドが置いたカードをすべて見つけます。文字はすべてMarkdownにあり、スペイン語、英語、日本語の三版があります。このページは日本語版です。

## 作り方

### 1 · 二ページで一枚のシート

<Excerpt region="answer" />

`spread: true`でテンプレートは二ページ分の幅の一枚のシートになり、ページのブロックも`spread`で同じことを示します。見開きは左ページから始まるので、ビルドに`continuation: { pageIndexOffset: 1, pageNumbering: { startAt: 48 } }`を渡します。この抜粋の1ページ目は本の48ページ、左ページになり、前に白ページは入りません。グリッドは一ページに一列で、列の間はのど側の余白の二倍です。のどに近づくのは帯だけです。二本目の帯は`crossGutter`と左の36mmの余白を取ります。色は一本目の帯の端から続いてのどをまたぎ、文字は右ページから始まります。文字が読まれるのも右ページです。

### 2 · グリッドが繰り返す一枚のカード

<Excerpt region="cards" />

`kind: 'grid'`に`repeat: { frames: ['asia'] }`を指定したグループは、ページにある`:::frame{slot="asia"}`の数だけ`asia`の枠を置きます。一行に三枚、テンプレートのグリッドの`col: 1`のセル、6行目から12行目までです。複製の名前は`#asia[1]`、`#asia[2]`、`#asia[3]`で、それぞれ自分のブロックの`label`、つまりタブの年を受け取ります。カードの高さは最低`minHeight`で、それより上は`auto`です。スペイン語版と日本語版の1844年のように文章が長くなると、その行が高くなり、同じ行のほかのカードも同じ高さまで伸びます（`rowAlign`の既定値は`'stretch'`です）。Markdownに四つ目の日付を足すと一行目の下に二行目ができ、テンプレートは変わりません。

### 3 · 帯ごとに一本のコネクタ

<Excerpt region="ticks" />

線は、テンプレートの装飾（`decoration`）に帯ごとに一本ずつ置いた`connector`です。`routing: 'tree'`は一つの親を多くの子につなぎます。`trunk: 0`では自分の横棒を描かず、帯の下端から各カードの上端の中央へまっすぐ線を下ろすだけです。`startCap: 'ring'`は各線の頭、帯の2.4mm下（`gap`）に輪を置きます。輪は線の太さで描いた中の空いた点で、外側の差し渡しは3.6mm（`capSize`）です。線は輪の外周で止まるので、輪の中にはクリーム色の地が見えます。`#asia[*]`はグリッドがそのページに置いたすべてのカードを指すので、Markdownで日付を足したり消したりすると、その線も増えたり減ったりします。コネクタは枠を置いたあとに配置されるので、行が高くなっても線はカードに届きます。クリーム色の地も装飾で、塗り足しの下端に固定した箱です。高さは`#band-1`の下端まで届くので（`size: { height: { to: '#band-1', edge: 'bottom' } }`）、帯に付いて動きます。

### 4 · 印刷の大きさで置く絵

<Excerpt region="art" />

挿絵は幅1,000px、550ppiで、ページ上では46mmです。画像は拡大されません。グリッドの三つの等幅の列は各ページで56.3mmなので、どの画像もカードの3.5mmの余白の内側にそのままの大きさで収まり、残りは文章に使われます。

## アレンジ

### 一行に四枚並べる

`columns: 4`にすると、帯ごとに四つの日付が横に並びます。カードが狭くなって文章の行数が増え、行は下へ伸びます。

```diff
-const row = (name, col) => ({ name: `${name}-row`, kind: 'grid', columns: 3, columnGap: mm(5),
+const row = (name, col) => ({ name: `${name}-row`, kind: 'grid', columns: 4, columnGap: mm(5),
```

### 輪の代わりに矢印を付ける

`endCap: 'arrow'`で各線がカードに届くところに矢じりが付き、`startCap: 'none'`で輪が消えます。

## よくあるつまずき

- グリッドは項目ごとにセルを一つ置き、項目とは一つずつ独立した`:::frame{slot="asia"}`ブロックです。二枚分の文章を一つのブロックに入れると、カードは一枚になります。
- `[*]`の付かない`#asia`はグリッドの箱で、カードではありません。そこへつないだコネクタは、行の中央へ線を一本下ろすだけです。
- 別の箱の端まで届く大きさは、要素自身の固定点から数えます。クリーム色の地は塗り足しの下端に固定し、上へ`#band-1`まで伸びます。固定点の後ろにある端は、高さ0になります。
