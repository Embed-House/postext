## 成品一览

初中历史课本的第48、49页：《纸的旅程》，从蔡伦的作坊到凯勒的磨石，造纸术走过的一千年。左页是标题和两段导语，右页是一个方框，讲手工抄一张纸的步骤。年表从两页中间横穿而过：亚洲一段用靛蓝色带，欧洲一段用赭红色带，后者从左页开始，跨过书脊。色带下面挂着六张卡片，每张有一幅插图，用一个圆环和一条竖线连到色带上。模板里只有一张亚洲卡片、一张欧洲卡片，每条色带一条连接线：网格组按Markdown里的每个日期放一张卡片，连接线再找到网格放下的所有卡片。所有文字都写在Markdown里，有西班牙语、英语和日语三个版本；本页显示西班牙语版。

## 做法

### 1 · 两页共用一张纸

<Excerpt region="answer" />

`spread: true`把模板变成一张和两页一样宽的纸，页面块也用`spread`标明这一点。跨页从左页开始，所以排版时传入`continuation: { pageIndexOffset: 1, pageNumbering: { startAt: 48 } }`：这段节选的第1页就是书的第48页，是左页，前面不需要空白页。网格每页一栏，两栏之间的间距是内侧页边距的两倍，所以只有色带靠近书脊。第二条色带设了`crossGutter`和36毫米的左内边距：颜色接着第一条色带跨过书脊，文字从右页开始，排版也在右页读取这些文字。

### 2 · 一张卡片，由网格重复

<Excerpt region="cards" />

`kind: 'grid'`加上`repeat: { frames: ['asia'] }`的组，会为页面里的每个`:::frame{slot="asia"}`放一次`asia`框，每行三张，放在模板网格的`col: 1`单元里，占第6到第12行。这些副本叫`#asia[1]`、`#asia[2]`和`#asia[3]`，各自取自己那个块的`label`，也就是标签上的年份。卡片至少有`minHeight`那么高，超过就是`auto`：某段文字变长时（比如西班牙语版和日语版里1844年那张），它所在的行会长高，同一行的其他卡片也拉到同样的高度（`rowAlign`默认是`'stretch'`）。Markdown里再加第四个日期，就在第一行下面开出第二行，模板不用改。

### 3 · 每条色带一条连接线

<Excerpt region="ticks" />

这些竖线是模板装饰（`decoration`）里的`connector`，每条色带一条。`routing: 'tree'`把一个父元素连到多个子元素；设了`trunk: 0`就不画自己的横杠，只从色带底边垂直画到每张卡片上边的中点，`startCap: 'ring'`在每条竖线的顶端放一个圆环，位于色带下方2.4毫米处（`gap`）。圆环是按线宽描出的空心圆点，外缘直径3.6毫米（`capSize`）；竖线停在圆环外缘，所以环里露出米色的底。`#asia[*]`指网格在这一页放下的所有卡片，所以在Markdown里增删一个日期，它的竖线也随之增删。连接线在框排好之后才画，所以某一行长高时，竖线仍然连到卡片上。米色的底也是装饰：一个锚定在出血底边的方块，高度向上到`#band-1`的底边为止（`size: { height: { to: '#band-1', edge: 'bottom' } }`），所以它跟着色带走。

### 4 · 按印刷尺寸放的插图

<Excerpt region="art" />

插图宽1000像素，分辨率550 ppi，在页面上宽46毫米，而图片从不放大。网格的三栏等宽，每页每栏56.3毫米，所以每幅插图都能按原尺寸放进卡片3.5毫米的内边距里，卡片其余的地方留给文字。

## 变化

### 每行四张卡片

设成`columns: 4`后，每条色带下并排放四个日期；卡片变窄，文字占的行数变多，各行也随之往下长。

```diff
-const row = (name, col) => ({ name: `${name}-row`, kind: 'grid', columns: 3, columnGap: mm(5),
+const row = (name, col) => ({ name: `${name}-row`, kind: 'grid', columns: 4, columnGap: mm(5),
```

### 用箭头代替圆环

`endCap: 'arrow'`在每条竖线碰到卡片的地方画一个箭头，`startCap: 'none'`去掉圆环。

## 常见问题

- 网格每个条目放一个单元格，而一个条目就是一个单独的`:::frame{slot="asia"}`块：把两张卡片的文字写在同一个块里，只会得到一张卡片。
- 不带`[*]`的`#asia`指的是网格本身的方框，而不是里面的卡片：连到它的连接线只画一条竖线，落在这一行的正中。
- 延伸到另一个方框边缘的尺寸，从元素自己的锚点算起：米色的底锚定在出血底边，向上长到`#band-1`。位于锚点后方的边，得到的高度是0。
