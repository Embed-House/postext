## 成品一览

初中历史课本的第48、49页：《纸的旅程》，从蔡伦的作坊到凯勒的磨石，造纸术走过的一千年。左页是标题和两段导语，右页是一个方框，讲手工抄一张纸的步骤。年表从两页中间横穿而过：亚洲一段用靛蓝色带，欧洲一段用赭红色带，后者从左页开始，跨过书脊。色带下面挂着六张卡片，每张有一幅插图，用一个圆点和一条短线连到色带上。这些卡片互相分配宽度：1844年那张故事最长，从两边的卡片借来宽度（西班牙语版1毫米，日语版7毫米），它的圆点也跟着移动。所有文字都写在Markdown里，有西班牙语、英语和日语三个版本；本页显示西班牙语版。

## 做法

### 1 · 两页共用一张纸

<Excerpt region="answer" />

`spread: true`把模板变成一张和两页一样宽的纸，页面块也用`spread`标明这一点。跨页从左页开始，所以排版时传入`continuation: { pageIndexOffset: 1, pageNumbering: { startAt: 48 } }`：这段节选的第1页就是书的第48页，是左页，前面不需要空白页。网格每页一栏，两栏之间的间距是内侧页边距的两倍，所以只有色带靠近书脊。第二条色带设了`crossGutter`和36毫米的左内边距：颜色接着第一条色带跨过书脊，文字从右页开始，排版也在右页读取这些文字。

### 2 · 互相分配宽度的卡片

<Excerpt region="cards" />

每行三张卡片是一个`row`组，每张卡片有`minHeight`，也就是它画出来的高度，超过这个高度就是`auto`。某张卡片的文字超出这一行的高度时，它向带`shrink`的相邻卡片借来所需的最少整毫米数，每张相邻卡片都保留足够放下自己文字的宽度。只有借不到时，这一行才往下长。西班牙语版里，1844年的卡片从1282年那张借1毫米；日语版里借7毫米，从1150年那张借3毫米，从1282年那张借4毫米。把所有文字加长30%（测试台的压力测试）时，西班牙语版借到15毫米，方框和导语的文字分别缩到92.5%和85%。

### 3 · 跟着卡片走的圆点

<Excerpt region="marks" />

圆点和短线是模板的装饰（`decoration`），以上边（`top`）锚定在`#c1` … `#c6`上，再往上提到色带的位置。装饰在框排好之后才放，所以卡片移动或变宽时，圆点始终在它的正中上方。米色的底也是装饰：一个锚定在出血底边的方块，高度向上到`#band-1`的底边为止（`size: { height: { to: '#band-1', edge: 'bottom' } }`），所以它跟着色带走。

### 4 · 按印刷尺寸放的插图

<Excerpt region="art" />

插图宽1000像素，分辨率550 ppi，在页面上宽46毫米，而图片从不放大：变宽的卡片保持插图大小，把多出来的地方留给文字。比53毫米（插图加两侧各3.5毫米的内边距）窄的卡片会把插图缩小，测试台的压力测试在日语版里就看到了：1150年和1282年两张的插图缩到85%。

## 变化

### 让卡片保持同样宽度

设成`shrink: 0`后，没有卡片让出宽度：这一行改为往下长，三张卡片一起，行的下沿随之下移。

```diff
-  shrink: 1, // a card gives width to a neighbour whose text runs past the row
+  shrink: 0,
```

## 常见问题

- 固定`height`的卡片不参与宽度的分配，因为它从不超出这一行：请像这里一样给卡片设`minHeight`，高度留作`auto`。
- 延伸到另一个方框边缘的尺寸，从元素自己的锚点算起：米色的底锚定在出血底边，向上长到`#band-1`。位于锚点后方的边，得到的高度是0。
