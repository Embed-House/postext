## 成品一览

《Our river》是一本虚构的三年级社会课本的第 4 单元，这里排了九页，开本 210 × 280 mm，有西班牙语、加泰罗尼亚语和英语三版。单元开篇是一幅画出来的河谷，接着是列出两个篇目的目录页，然后是三个跨页主题，每个主题各有底色：水的蓝、田野的绿、阳光的沙色。每个主题都有写着编号和标题的标签、两栏文字，以及带页签、随文字变高的框。第二个主题是一幅横跨两页的手绘地图，河流、村镇和三个河段的名字都由 Markdown 标在图上。三种语言的篇幅相差五分之一以上，却排进同一套模板：框按文字需要变高，把下一个框往下推，而地图会比任何文字先缩小一点。

## 做法

### 1 · 用 `extends` 搭出各种框

<Excerpt region="boxes" />

框样式分三步做成。`caja` 保存形状、字体和页签的几何；`caja-tema` 把主题的颜色加到页签和项目符号上；`dato`、`palabras`、`actividad` 决定种类：带底色的框、带描边的框、带色条的框。它们的颜色是调色板条目（`tema`、`tema-tint`），所以每个样式只写一次，由主题的模板给它上色。

### 2 · 让每个主题继承同一个底板模板

<Excerpt region="answer" />

底板是一个跨页模板：铺到出血位的底色、带编号的标题标签，以及两栏文字。每个主题用 `extends: 'tema'` 继承它，设置自己的 `palette`（三个 `tema` 条目取该色系的颜色，底色、标签、编号和所有框一起变），再加上自己的框。标签和编号是锚定在标题框上的装饰，所以标签的高度正好是这种语言的标题所需。编号是 `{headingNumber}`，即标题框所取标题的计数，画在框的左内边距上：页面块里不再重复写它，点击它会点到编号，而不是框。

### 3 · 让各组自己分配空间

每个主题有两个组。左页是一个堆叠组：标题、文字，然后是配图条或地图。右页是另一个由框组成的堆叠组，或者是三个框平分宽度的一行。框和自己的文字一样高，但不低于 `minHeight`，所以西班牙语的文字会把下面的一切往下推，模板里没有任何位置需要改。页面不够用时，[重排阶梯](/zh/docs/composed-pages#仍然放不下时)先收回空间，再缩小地图和图片，文字放在最后，最多缩到 90 %。`pnpm cookbook bench` 会把三个版本的文字加长 30 % 再排一遍。

### 4 · 按正文给地图标上名字

<Excerpt region="art-labels" />

地图是一幅没有一个字母的绘画。每个地点是图上的一个锚点，用占图宽和图高的比例表示，并带一种标注样式；各版本在这些锚点上写自己的 `::label` 行。*Penalta Reservoir*、*Pantà de Penyalta* 和 *Embalse de Peñalta* 站在同一个位置上，更长的名字会在锚点的 `width` 里换行。

### 5 · 让目录的每一篇不被拆开

<Excerpt region="contents" />

`:::toc{keep="part" levels="1-2"}` 列出各个主题和小节，并让每个篇名行和它的条目待在一起。带 `parts.page: false` 的 `:::part` 围栏只是目录里的一行，也是running head的一个分节，不会多出一页扉页。目录是一张模板页：它的模板有一个 `takes: "toc"` 的框，接收 `:::toc` 并按目录自己的规则排版，所以篇名行、点状前导符和 `keep` 都和正文里一样有效，浅色底色则是模板的装饰。

## 变化

### 再加一个色系

一个讲海的主题，就是 `FAMILIES` 里的第四项，再加一个用 `topic('tema-mar', 'mar', { frames })` 做的模板。`swap('mar')` 写出它的调色板，框和底色随之变化。

```diff
-  sol: { main: '#9a5209', tint: '#fcefd2', ground: '#f8e6b8' },
+  sol: { main: '#9a5209', tint: '#fcefd2', ground: '#f8e6b8' },
+  mar: { main: '#0f5a6b', tint: '#dcf0f2', ground: '#cbe6ea' },
```

### 让文字保持原来的字号

不能缩小文字的框写 `fit: { shrinkText: false }`。这样较长的文字会更用力地推周围的框，阶梯也会更早轮到图片。

```diff
-  frames: [title, { name: 'texto', flow: true, columns: 2, columnGap: mm(7), width: mm(HALF),
-    fit: { minScale: 0.9 } }],
+  frames: [title, { name: 'texto', flow: true, columns: 2, columnGap: mm(7), width: mm(HALF),
+    fit: { shrinkText: false } }],
```

## 常见问题

- 画进图里的名字无法随语言改变：地图上没有任何文字，每个地名都是一个标注。
主题的调色板只改 `tema` 条目。页码圆标和目录用的是 `agua`，它的蓝色相同，所以在绿色和沙色页面上仍是蓝色；把它们链接到 `tema`，就会跟着主题走。
- 两处图框使用同一个资源时，两处都取第一处写的文字：目录页上的小地图是同一个文件，用另一个资源 `rio`，不带锚点。
