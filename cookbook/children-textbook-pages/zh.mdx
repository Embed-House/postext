## 成品一览

《我们的河流》是一本虚构的三年级社会课本的第 4 单元，这里排了九页，开本 210 × 280 mm，共有十种语言：西班牙语、加泰罗尼亚语、英语、葡萄牙语、法语、德语、意大利语、阿拉伯语、中文和日语。单元开篇是一幅画出来的河谷，接着是列出两个篇目的目录页，然后是三个跨页主题，每个主题各有底色：水的蓝、田野的绿、阳光的沙色。每个主题都有写着编号和标题的标签、两栏文字，以及带页签、随文字变高的框。第二个主题是一幅横跨两页的手绘地图，河流、村镇和三个河段的名字都由 Markdown 标在图上。各语言的篇幅相差五分之一以上，却排进同一套模板：框按文字需要变高，把下一个框往下推，而地图会比任何文字先缩小一点。阿拉伯语版从右往左排，中文版和日文版从上往下排；这三本都在右侧装订，每个跨页先读右页，再读左页。

## 做法

### 1 · 弄清每种语言从哪一侧开始

<Excerpt region="editions" />

模板里的框位于页面的流向坐标系中，x 沿着行的方向延伸。设置 `locale: 'ar'` 时，引擎把这个坐标系左右镜像，所以阿拉伯语版原样使用拉丁文的框：标题先出现在右页，三张照片和三个河段框从右往左排，框的页签、色条和内边距都跟着行走。设置 `layout.writingMode: 'vertical-rl'` 时，x 沿页面向下，y 从右往左：框的 `width` 是向下的长度，堆叠组向左推进，`columns: 2` 分出上下两栏（段），每栏 27 个字，放在另一个框 `below` 的框位于它的左边。装饰（底色、标题标签、编号、书眉和页码）放在纸面本身上，所以从 `START` 定位，也就是页面开始阅读的那一侧。每种文字都有一款正文字体和一款圆体标题字体，阿拉伯语、中文和日文版不用斜体、大写字母和字距调整。

### 2 · 用 `extends` 搭出各种框

<Excerpt region="boxes" />

框样式分三步做成。`caja` 保存形状、字体和页签的几何；`caja-tema` 把主题的颜色加到页签和项目符号上；`dato`、`palabras`、`actividad` 决定种类：带底色的框、带描边的框、带色条的框。它们的颜色是调色板条目（`tema`、`tema-tint`），所以每个样式只写一次，由主题的模板给它上色。

### 3 · 让每个主题继承同一个底板模板

<Excerpt region="answer" />

底板是一个跨页模板：铺到出血位的底色、带编号的标题标签，以及两栏文字。每个主题用 `extends: 'tema'` 继承它，设置自己的 `palette`（三个 `tema` 条目取该色系的颜色，底色、标签、编号和所有框一起变），再加上自己的框。标签和编号是锚定在标题框上的装饰，所以标签的高度正好是这种语言的标题所需。编号是 `{headingNumber}`，即标题框所取标题的计数，画在框中文字之前的内边距上：页面块里不再重复写它，点击它会点到编号，而不是框。

### 4 · 让各组自己分配空间

每个主题有两个组。左页是一个堆叠组：标题、文字，然后是配图条或地图。右页是另一个由框组成的堆叠组，或者是三个框平分宽度的一行。框和自己的文字一样高，但不低于 `minHeight`，所以西班牙语的文字会把下面的一切往下推，模板里没有任何位置需要改。页面不够用时，[重排阶梯](/zh/docs/composed-pages#仍然放不下时)先收回空间，再缩小地图和图片，文字放在最后，最多缩到 90 %。`pnpm cookbook bench` 会把每个版本的文字加长 30 % 再排一遍。在竖排页面上，田野绿的跨页把地图横铺在两页的天头，标题、文字和三个河段排在它下面。

### 5 · 按正文给地图标上名字

<Excerpt region="art-labels" />

地图是一幅没有一个字母的绘画。每个地点是图上的一个锚点，用占图宽和图高的比例表示，并带一种标注样式；各版本在这些锚点上写自己的 `::label` 行。*Penalta Reservoir*、*Pantà de Penyalta* 和 *Embalse de Peñalta* 站在同一个位置上，更长的名字会在锚点的 `width` 里换行。右侧装订的书使用同一幅画的镜像（`mapa-1900-rtl.jpg`），这样河流从右边的山流向左边的海，与页面的阅读方向一致；`flipped` 把每个锚点移到另一侧，并把旋转反过来。

### 6 · 让目录的每一篇不被拆开

<Excerpt region="contents" />

`:::toc{keep="part" levels="1-2"}` 列出各个主题和小节，并让每个篇名行和它的条目待在一起。带 `parts.page: false` 的 `:::part` 围栏只是目录里的一行，也是running head的一个分节，不会多出一页扉页。目录是一张模板页：它的模板有一个 `takes: "toc"` 的框，接收 `:::toc` 并按目录自己的规则排版，所以篇名行、点状前导符和 `keep` 都和正文里一样有效，浅色底色则是模板的装饰。

## 变化

### 再加一个色系

一个讲海的主题，就是 `FAMILIES` 里的第四项，再加一个用 `topic('tema-mar', 'mar', { frames })` 做的模板。`swap('mar')` 写出它的调色板，框和底色随之变化。

```diff
-  sol: { main: '#9a5209', tint: '#fcefd2', ground: '#f8e6b8' },
+  sol: { main: '#9a5209', tint: '#fcefd2', ground: '#f8e6b8' },
+  mar: { main: '#0f5a6b', tint: '#dcf0f2', ground: '#cbe6ea' },
```

### 让文字保持原来的字号

不能缩小文字的框写 `fit: { shrinkText: false }`。这样较长的文字会更用力地推周围的框，阶梯也会更早轮到图片。

```diff
   frames: [title, { name: 'texto', flow: true, columns: 2, columnGap: mm(CJK ? 16 : 7), // 段
-    width: mm(MEASURE), fit: { minScale: 0.9 } }],
+    width: mm(MEASURE), fit: { shrinkText: false } }],
```

## 常见问题

- 画进图里的名字无法随语言改变：地图上没有任何文字，每个地名都是一个标注。
- 主题的调色板只改 `tema` 条目。页码圆标和目录用的是 `agua`，它的蓝色相同，所以在绿色和沙色页面上仍是蓝色；把它们链接到 `tema`，就会跟着主题走。
- 阿拉伯-印度数字紧挨着中点时会读成两个数字：`١ · ماء` 看起来像 `٠١ ماء`，因为阿拉伯语的零是一个点。阿拉伯语版写成 `١- ماء للحقول`，单元编号则用文字写出。
- 装饰元素位于纸面上，不在文字流里：放在框 `top-left` 位置的徽标，在阿拉伯语版里仍在左边。`corner('top')` 和 `inward(x)` 从页面开始阅读的那一侧定位它。
- 两处图框使用同一个资源时，两处都取第一处写的文字：目录页上的小地图是同一个文件，用另一个资源 `rio`，不带锚点。
