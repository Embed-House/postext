# わたしたちの川 {style="portada"}

あなたが知っている町や村は、どれも水の近くにあります。この{単元|たん|げん}では、アルダラ川を、川が生まれる雪の山から、川が終わる海まで追っていきます。川がどこで生まれるのか、下っていくとどのようにかわるのか、そして、フォンタルバ、モリナール、アルダマールの人びとが川のそばでどのようにくらしているのかを学びます。

:::frame{slot="aprenderas" label="学ぶこと"}
- わき水が谷川になり、谷川が川になるようす。
- 川の上流・中流・下流とは、どんなところか。
- 人びとが川の水をどのように使い、川をどのように大切にしているか。
:::

# 川が生まれるところ

山には雨や雪がふります。その水の一部は山の{斜面|しゃ|めん}を流れ下り、一部は土の中にしみこみます。土の中の水はゆっくり進み、通りぬけられない岩につき当たります。すると、そこから地上に出てきます。水が地面からわき出るところを**わき水**といいます。

## わき水から谷川へ

一つのわき水から出る水は、糸のように細い流れです。細い流れは{斜面|しゃ|めん}を下り、ほかの流れといっしょになって**谷川**になります。急な坂では、谷川は速く流れます。小石を運び、何度も転がして丸くします。いくつかの谷川が集まると、大きな流れになります。アルダラ川もこのようにして、シエラ・ブランカ山地の雪の中、海面から千八百五十メートルの高さで生まれます。

::caption[わき水。この水は、何か月も土の中を通ってきました。]
:::

:::figure{resource="arroyo" slot="foto-2"}

::caption[谷川。坂が急で流れが速く、小石はつるつるです。]
:::

:::figure{resource="cascada" slot="foto-3"}
::alt[緑色のふちに落ちる小さなたき。]
::caption[たき。谷川が岩の{段|だん}から落ちるところです。]

:::frame{slot="probar" label="やってみよう"}
ぬれたスポンジをおぼんの上で持ち、そっとにぎりましょう。水はどこから出てきますか。水がぽたぽた落ち、やがて流れ出すようすを見ましょう。わき水も、このようにして谷川に水を送っています。
:::

:::frame{slot="sabias" label="知っているかな？"}
生まれたばかりのアルダラ川は、とびこえられるほどの細い流れです。九十四キロメートル流れたあとには、川はばがサッカー場のたての長さほどになります。
:::

:::frame{slot="palabras" label="大切なことば"}
**わき水：**地面から水がわき出るところ。

**谷川：**坂を速く流れ下る、小さな川。

**{支流|し|りゅう}：**大きな川に流れこむ谷川や川。

**川岸：**川の両がわの土地。
:::

:::frame{slot="actividades" label="たしかめよう"}
1. 三まいの絵を見ましょう。わき水がかかれているのはどれですか。どうしてわかりますか。
2. 山の中では、平地よりも谷川が速く流れます。それはどうしてでしょうか。
3. 「大切なことば」の四つのことばのうち、絵の中で見つけられるのはどれですか。
:::

# 山から海へ

アルダラ川の長さは九十四キロメートルです。シエラ・ブランカ山地で生まれ、谷と平野を通って、アルダマールで海に出ます。地理を研究する人は、川を山に近いほうから三つの部分に分けて考えます。それぞれを**上流**・**中流**・**下流**といい、どれも様子がちがいます。

:::frame{slot="actividad" label="地図を見よう"}
生まれるところから海まで、指で川をなぞりましょう。海にいちばん近い町はどこですか。
:::

:::frame{slot="curso-1" label="上流"}
坂が急です。水はつめたく、すんでいて、流れが速く、岩をけずります。ここにフォンタルバがあります。
:::

:::frame{slot="curso-2" label="中流"}
谷が広くなり、川の流れはゆるやかになります。農家の人は田畑に水を引きます。モリナールは、橋と水車小屋のまわりに広がった町です。
:::

:::frame{slot="curso-3" label="下流"}
土地はほとんど平らです。川ははばが広く、ゆっくり流れて、大きく曲がります。アルダマールで海に流れこみます。
:::

# 人びとと川

人びとは、昔から川の近くに住んできました。飲むための水、体をあらうための水、作物を育てるための水がいるからです。川は魚をくれます。船の通り道にもなり、水車を回す力も生み出します。

## 川を大切に

川は、わたしたちが守らなければ、きれいなままではいられません。ごみや油、よごれた水は川を病気にし、そこにすむ魚や植物が苦しみます。台所の流しや道路に流したものは、やがてみんな川や海に行きつきます。

:::frame{slot="cuidar" label="わたしたちの川を守ろう"}
- ごみはごみ箱にすて、川にはけっしてすてません。
- 水を大切に使い、じゃ口をしめます。
- 決められた道を歩き、植物や動物をいためません。
- 学校で川岸のそうじをするときは、いっしょに手つだいます。
:::

:::frame{slot="turno" label="あなたのばん"}
1. わたしたちの川をきれいにするための、三つのきまりを書いたポスターをかきましょう。
2. 「家のじゃ口から出る水は、どこから来ているの？」と、家の人に聞いてみましょう。
:::

:::frame{slot="uso-1" label="一　田畑の水"}
中流では、農家の人が小さな用水路をつくり、川の水を畑のうねの間に流します。この水がなければ、夏にトマトやレタスは育ちません。一本の用水路が、何キロメートルも先まで水を運ぶこともあります。
:::

::alt[やさい畑で、用水路の水門を上げる農家の人。]
:::

:::frame{slot="uso-2" label="二　水車小屋"}
昔、モリナールの水車小屋では、落ちる水が水車を回していました。水車は石うすを回して小麦をひき、谷に住む人みんなのための{小麦粉|こ|むぎ|こ}を作りました。今、古い水車小屋は小さな{博物館|はく|ぶつ|かん}になっています。
