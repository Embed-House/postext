# 河流从哪里来

山上会下雨，也会下雪。一部分水顺着山坡流下去，一部分渗进土里。水在地下慢慢地走，直到碰上一块穿不过去的岩石，这时它就流到地面上来。地下水从地里冒出来的地方，叫作**泉眼**。

## 从泉眼到小溪

一个泉眼只流出细细的一股水。细流顺着山坡往下流，遇到别的细流，合在一起就成了**小溪**。山坡很陡，小溪就流得很急。它推着小石子往前滚，把石子磨得光溜溜的。几条小溪汇到一起，就成了一条更大的溪流。阿尔达拉河就是这样开始的。它的源头在白山的积雪里，比海平面高一千八百五十米。

:::frame{slot="probar" label="试一试"}
把一块湿海绵拿在托盘上方，轻轻地挤一挤。水从哪里出来？看看它先是一滴一滴往下落，后来又流成一股。泉眼就是这样给小溪送水的。
:::

:::frame{slot="sabias" label="你知道吗？"}
在源头，阿尔达拉河只是一股细流，一步就能跨过去。流了九十四公里以后，它的宽度和一个足球场的长度差不多。
:::

:::frame{slot="palabras" label="学习新词"}
**泉眼**：地下水从地里冒出来的地方。

**小溪**：从山坡上很快流下来的小河。

**支流**：流进另一条更大的河的小溪或河流。

**河岸**：河流两边的陆地。
:::

# 从高山到大海

阿尔达拉河长九十四公里。它发源于白山，穿过一条山谷和一片平原，在阿尔达马尔流进大海。地理学家把一条河分成三段，分别叫作**上游**、**中游**和**下游**。每一段的样子都不一样。

:::frame{slot="curso" label="上游"}
山坡很陡。河水又冷又清，流得很急，不停地冲刷着岩石。丰塔尔巴就在这里。
:::

:::frame{slot="curso" label="中游"}
山谷变宽了，河水流得慢了。农民用河水浇地。莫利纳尔是在一座桥和一座磨坊旁边发展起来的。
:::

:::frame{slot="curso" label="下游"}
地面差不多是平的。河面很宽，水流很慢，转出一个个大弯。河水在阿尔达马尔流进大海。
:::

# 人与河流

人们一直喜欢住在河流附近。他们要用水来喝、来洗东西，还要用水种庄稼。河流还给人们送来鱼，给小船一条路，还能推动水轮转起来。

## 保护河流

只有我们好好爱护，河流才能保持干净。垃圾、废油和脏水会让河流生病，生活在河里的鱼和植物也会受到伤害。从下水道或街道上流走的东西，最后都会流进河里或大海里。

:::frame{slot="cuidar" label="爱护我们的河"}
- 把垃圾扔进垃圾桶，绝不扔进水里。
- 节约用水，用完随手关水龙头。
- 走在小路上，不打扰植物和动物。
- 学校组织清理河岸时，我们一起去帮忙。
:::

:::frame{slot="turno" label="轮到你了"}
1. 画一张海报，写上三条让我们的河保持干净的规定。
2. 回家问一问：你家水龙头里的水是从哪里来的？
:::

:::frame{slot="uso" label="一　农田用水"}

:::frame{slot="uso" label="二　磨坊"}
