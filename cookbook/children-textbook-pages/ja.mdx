## できあがり

架空の小学3年生の社会科の本の第4単元「Our river」を、210 × 280 mm のページで9ページ、スペイン語、カタルーニャ語、英語の3版で組みます。描いた谷が単元を開き、二つの部を並べた目次のページがあり、そのあとにテーマが3つ、見開きで続きます。地色は水の青、野の緑、日の砂色とテーマごとに違います。どのテーマにも番号とタイトルのタブがあり、本文は2段、囲みは文章に合わせて伸びるタブ付きです。2つ目のテーマは2ページにまたがる1枚の絵の地図で、川、村、三つの区間の名前を Markdown から載せます。三つの本文は5分の1以上も長さが違いますが、同じテンプレートに収まります。囲みは言葉に必要な高さを取って次の囲みを押し下げ、地図は文字より先に少しだけ縮みます。

## 作り方

### 1 · 囲みを `extends` で作る

<Excerpt region="boxes" />

囲みのスタイルは3段階で作ります。`caja` が形、書体、タブの寸法を持ち、`caja-tema` がテーマの色をタブと箇条書きの記号に付け、`dato`、`palabras`、`actividad` が種類（地色の囲み、枠線の囲み、色帯の囲み）を決めます。色はパレットの項目（`tema`、`tema-tint`）なので、各スタイルは一度書けば足り、テーマのテンプレートがそれに色を付けます。

### 2 · すべてのテーマに土台のテンプレートを引き継がせる

<Excerpt region="answer" />

土台は見開きのテンプレートで、裁ち落としまでの地色、番号付きのタイトルのタブ、2段の本文を持ちます。各テーマは `extends: 'tema'` でこれを引き継ぎ、自分の `palette` を決め（3つの `tema` 項目が系統の色になり、地色、タブ、番号、すべての囲みが一度に変わります）、自分のフレームを足します。タブと番号はタイトルのフレームに固定した装飾なので、タブの高さはその言語のタイトルに必要なだけになります。番号は `{headingNumber}`、つまりフレームが受け取った見出しのカウンターで、フレームの左の余白に描かれます。ページのフェンスで番号を繰り返す必要はなく、番号をクリックするとフレームではなく番号に届きます。

### 3 · グループに場所を分け合わせる

テーマにはグループが二つあります。左ページは、タイトル、本文、そして絵の帯か地図を積むスタックです。右ページは囲みを積むもう一つのスタックか、幅を分け合う3つの囲みの行です。フレームは言葉の分だけ高くなり、`minHeight` より低くなることはないので、スペイン語の本文は下にあるものをすべて押し下げ、テンプレートの位置は何も変わりません。ページが窮屈になると、[調整の手順](/ja/docs/composed-pages#それでも収まらないとき)がまず空きを取り戻し、地図と絵を縮め、本文は最後に90 %まで縮めます。`pnpm cookbook bench` は、本文を30 %長くして3つの版をもう一度組みます。

### 4 · 地図の名前を本文から付ける

<Excerpt region="art-labels" />

地図は文字が一つもない絵です。それぞれの場所は絵の上のアンカーで、幅と高さに対する割合の点とラベルのスタイルを持ち、各版がそのアンカーに自分の `::label` の行を書きます。*Penalta Reservoir*、*Pantà de Penyalta*、*Embalse de Peñalta* は同じ位置に立ち、長い名前はアンカーの `width` の中で折り返します。

### 5 · 目次の部をまとめておく

<Excerpt region="contents" />

`:::toc{keep="part" levels="1-2"}` はテーマと節を並べ、部の行をその項目と離さずに保ちます。`parts.page: false` を付けた `:::part` のフェンスは、目次の一行と柱の区切りになるだけで、扉のページは増えません。目次は構成ページです。そのテンプレートには `takes: "toc"` の枠があり、`:::toc` を受け取って目次自身の規則で組みます。部の行、リーダー、`keep` は本文の中と同じように働き、淡い地はテンプレートの装飾です。

## アレンジ

### 4つ目の系統を足す

海のテーマなら、`FAMILIES` に4つ目の項目を足し、`topic('tema-mar', 'mar', { frames })` でテンプレートを作ります。`swap('mar')` がそのパレットを書き、囲みと地色はそれに従います。

```diff
-  sol: { main: '#9a5209', tint: '#fcefd2', ground: '#f8e6b8' },
+  sol: { main: '#9a5209', tint: '#fcefd2', ground: '#f8e6b8' },
+  mar: { main: '#0f5a6b', tint: '#dcf0f2', ground: '#cbe6ea' },
```

### 本文の大きさを保つ

本文を縮めてはいけないフレームには `fit: { shrinkText: false }` を付けます。長い本文は周りのフレームをより強く押し、手順は絵のほうへ早く進みます。

```diff
-  frames: [title, { name: 'texto', flow: true, columns: 2, columnGap: mm(7), width: mm(HALF),
-    fit: { minScale: 0.9 } }],
+  frames: [title, { name: 'texto', flow: true, columns: 2, columnGap: mm(7), width: mm(HALF),
+    fit: { shrinkText: false } }],
```

## よくあるつまずき

- 絵に描き込んだ名前は言語に合わせて変えられません。地図には文字がなく、地名はすべてラベルです。
テーマのパレットが変えるのは `tema` の項目だけです。ノンブルと目次は同じ青の `agua` を使うので、緑や砂色のページでも青のままです。`tema` にリンクすれば、テーマに従います。
- 同じリソースを指定する2つの図は、最初の図の言葉を取ります。目次ページの小さな地図は同じファイルを別のリソース `rio` として使い、アンカーを持ちません。
