## できあがり

架空の小学3年生の社会科の本の第4単元「わたしたちの川」を、210 × 280 mmのページで9ページ、スペイン語、カタルーニャ語、英語、ポルトガル語、フランス語、ドイツ語、イタリア語、アラビア語、中国語、日本語の10か国語で組みます。描いた谷が単元を開き、二つの部を並べた目次のページがあり、そのあとにテーマが3つ、見開きで続きます。地色は水の青、野の緑、日の砂色とテーマごとに違います。どのテーマにも番号とタイトルのタブがあり、本文は2段、囲みは文章に合わせて伸びるタブ付きです。2つ目のテーマは2ページにまたがる1枚の絵地図で、川、村、三つの区間の名前をMarkdownから載せ、区間の囲みそれぞれから川のその区間へ線を引きます。繰り返すものは一度だけ描きます。テンプレートは、画像のカード、区間の囲み、画像付きの囲みをそれぞれ一つずつ持ち、Markdownが求める数だけ並べます。単元の初めの三つの問いは、一つのモジュールを3回使ったものです。本文は言語によって5分の1以上も長さが違いますが、同じテンプレートに収まります。囲みは言葉に必要な高さを取って次の囲みを押し下げ、地図は文字より先に少しだけ縮みます。アラビア語の本は右から左へ、中国語と日本語の本はページを上から下へ進みます。三つとも右綴じで、見開きごとに右ページから左ページへと読みます。

## 作り方

### 1 · 言語ごとにどちら側から始まるかを知る

<Excerpt region="editions" />

テンプレートの枠はページの流れの座標系の中にあり、xは行に沿って進みます。`locale: 'ar'`を指定すると、エンジンはこの座標系を左右反転させるので、アラビア語の本はラテン文字用の枠をそのまま使えます。タイトルは右ページに先に来て、写真3枚と川の区間の囲み3つは右から左へ並び、囲みのタブ、色帯、余白は行に従います。`layout.writingMode: 'vertical-rl'`では、xはページを下へ、yは右から左へ進みます。枠の`width`は下向きの長さになり、積み重ねは左へ進み、`columns: 2`は27字詰めの2段（段）になり、別の枠の`below`に置いた枠はその左に立ちます。装飾（地色、タイトルのタブ、番号、柱、ノンブル）は紙面そのものの上にあるので、ページの読み始めの側である`START`から配置します。文字体系ごとに本文用の書体と丸みのある見出し用の書体があり、アラビア語、中国語、日本語の版ではイタリック、大文字、字間の調整を使いません。

### 2 · 囲みを `extends` で作る

<Excerpt region="boxes" />

囲みのスタイルは3段階で作ります。`caja`が形、書体、タブの寸法を決め、`caja-tema`がテーマの色をタブと箇条書きの記号に付け、`dato`、`palabras`、`actividad`が種類（地色の囲み、枠線の囲み、色帯の囲み）を決めます。色はパレットの項目（`tema`、`tema-tint`）なので、各スタイルは一度書けば足り、テーマのテンプレートがそれに色を付けます。

### 3 · すべてのテーマに土台のテンプレートを引き継がせる

<Excerpt region="answer" />

土台は見開きのテンプレートで、塗り足しまでの地色、番号付きのタイトルのタブ、2段の本文があります。各テーマは`extends: 'tema'`でこれを引き継ぎ、自分の`palette`を決め（3つの`tema`項目が系統の色になり、地色、タブ、番号、すべての囲みが一度に変わります）、自分の枠を足します。タブと番号はタイトルの枠に固定した装飾なので、タブの高さはその言語のタイトルに必要なだけになります。番号は`{headingNumber}`、つまり枠が受け取った見出しのカウンターで、枠の、文字より前に来る側の余白に描かれます。ページブロックで番号を繰り返す必要はなく、番号をクリックすると枠ではなく番号に届きます。

### 4 · 繰り返すものは一度だけ描く

<Excerpt region="repeats" />

グリッドのグループは、ページの項目一つごとに枠の組を一度ずつ繰り返します。画像の帯は`grid('fotos', ['foto'], 3, …)`です。`:::figure{slot="foto"}`のブロックが三つあればカードが三枚になり、名前は`#foto[1]`から`#foto[3]`で、「やってみよう」の囲みは`#foto[1]`の下に付きます。日のテーマの囲みは1列のグリッドで、組は囲みとその画像です（`['uso', 'uso-foto']`）。`:::frame{slot="uso"}`のそれぞれが自分の言葉を持ち、その中に対応する`:::figure{slot="uso-foto"}`を入れます。問いのページはモジュールを積みます。`pregunta`は`role: 'module'`のテンプレートで、地色の囲みと答えを書く線があり、ページの`preguntas`グループ（`modules: true`）がMarkdownの`:::module{template="pregunta"}`一つごとに一つ置きます。枠は言葉の分だけ高くなり、`minHeight`より低くなることはないので、長いスペイン語の本文は下の行を押し下げます。ページが窮屈になると、[調整の手順](/ja/docs/composed-pages#それでも収まらないとき)が本文より先に地図と画像を縮め、本文は90 %まで縮めます。

区間の囲みは地図の下に並ぶ3つのグリッドです（`grid('cursos', ['curso'], 3, …)`）。`:::frame{slot="curso"}`一つにつき囲みが一つできます。地図は同じ三つの区間に`curso`スタイルのラベルで名前を付け、その地は囲みのタブと同じ緑なので、読み手は名前と色で囲みごとの区間を見つけられます。縦組みのページでは、区間の囲みが一列になって地図の横に立ちます。

### 5 · 地図の名前を本文から付ける

<Excerpt region="art-labels" />

地図は文字が一つもない画像です。それぞれの場所は画像の上のアンカーで、幅と高さに対する割合で表した点にラベルスタイルを指定したもので、各版がそのアンカーに自分の`::label`の行を書きます。*Penalta Reservoir*、*Pantà de Penyalta*、*Embalse de Peñalta* は同じ位置に立ち、長い名前はアンカーの`width`の中で折り返します。右綴じの本は同じ絵を左右反転して使う（`mapa-1900-rtl.jpg`）ので、川はページを読む向きのとおり、右の山から左の海へ流れます。`flipped`は各アンカーとそのラベルを置く位置を反対側に移し、回転を逆向きにします。「水源」と「ペニャルタダム湖」は`labelAt`で場所から離して置き、`agua`スタイルの`leader`が名前から水源とダムへ、点の付いた線を引きます。

### 6 · 目次の部をまとめておく

<Excerpt region="contents" />

`:::toc{keep="part" levels="1-2"}`はテーマと節を並べ、部の行をその項目と離さずに保ちます。`parts.page: false`を付けた`:::part`は、目次の一行と柱の区切りになるだけで、扉のページは増えません。目次はテンプレートページです。そのテンプレートには`takes: "toc"`の枠があり、`:::toc`を受け取って目次自身の規則で組みます。部の行、リーダー、`keep`は本文の中と同じように働き、淡い地はテンプレートの装飾です。

## アレンジ

### 4つ目の系統を足す

海のテーマなら、`FAMILIES`に4つ目の項目を足し、`topic('tema-mar', 'mar', { frames })`でテンプレートを作ります。`swap('mar')`がそのパレットを書き、囲みと地色はそれに従います。

```diff
-  sol: { main: '#9a5209', tint: '#fcefd2', ground: '#f8e6b8' },
+  sol: { main: '#9a5209', tint: '#fcefd2', ground: '#f8e6b8' },
+  mar: { main: '#0f5a6b', tint: '#dcf0f2', ground: '#cbe6ea' },
```

### 本文の大きさを保つ

本文を縮めてはいけない枠には`fit: { shrinkText: false }`を付けます。長い本文は周りの枠をより強く押し、手順は画像のほうへ早く進みます。

```diff
   frames: [title, { name: 'texto', flow: true, columns: 2, columnGap: mm(CJK ? 16 : 7), // 段
-    width: mm(MEASURE), fit: { minScale: 0.9 } }],
+    width: mm(MEASURE), fit: { shrinkText: false } }],
```

## よくあるつまずき

- 画像に描き込んだ名前は言語に合わせて変えられません。地図には文字がなく、地名はすべてラベルです。
- テーマのパレットが変えるのは`tema`の項目だけです。ノンブルと目次は同じ青の`agua`を使うので、緑や砂色のページでも青のままです。`tema`にリンクすれば、テーマに従います。
- アラビア・インド数字を中黒の隣に置くと、2桁の数字に見えます。アラビア語のゼロは点なので、`١ · ماء`は`٠١ ماء`のように見えます。アラビア語版は`١- ماء للحقول`と書き、単元の番号は言葉で書きます。
- 装飾の要素は流れではなく紙面の上にあります。枠の`top-left`に置いたバッジは、アラビア語でも左に残ります。`corner('top')`と`inward(x)`は、ページの読み始めの側からそれを配置します。
- グリッドでは、項目の一つひとつが独立したブロックです。囲みの画像がその組に入るのは、`:::figure`を囲みの`:::frame`の中に書いたときだけです。後ろに書くと、画像は別の項目になり、自分のセルを一つ取ります。
- 同じリソースを指定する2つの図は、最初の図の言葉を取ります。目次ページの小さな地図は同じファイルを別のリソース`rio`として使い、アンカーはありません。
