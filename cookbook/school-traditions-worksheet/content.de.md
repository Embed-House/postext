# Das Wasser auf Reisen {nombre="Name" fecha="Datum"}

Das Wasser auf der Erde ist immer unterwegs. Die Sonne erwärmt das Meer, das Wasser steigt in den Himmel und kommt als Regen oder Schnee wieder herunter. Diese Reise heißt Wasserkreislauf.

:::exercise
Kreuze die richtige Antwort an.

1. Wasser, das aus den Wolken fällt, heißt
   - [ ] Dampf
   - [x] Regen
   - [ ] Nebel
2. Wenn die Sonne das Meer erwärmt, dann
   - [x] verdunstet das Wasser
   - [ ] gefriert das Wasser
   - [ ] sinkt das Wasser
:::

:::exercise{type="truefalse"}
Richtig oder falsch? Kreuze an.

- [x] Wolken bestehen aus winzigen Wassertröpfchen.
- [ ] Eis schmilzt, wenn es kälter wird.
- [x] Flüsse bringen das Wasser zurück ins Meer.
- [ ] Regen ist salzig, weil er aus dem Meer kommt.
:::

:::exercise{bank}
Ergänze den Lückentext mit den Wörtern aus dem Kasten.

::bank[Eis | Wind]

Die Sonne erwärmt das [[Meer]]. Das Wasser wird zu [[Wasserdampf]] und steigt auf. Oben kühlt es ab und bildet [[Wolken]]. Dann fällt es als [[Regen]] oder Schnee herab.
:::

:::exercise
Verbinde jedes Wort mit seiner Bedeutung.

- Verdunstung -> Wasser wird zu Dampf
- Kondensation -> Dampf wird zu Tropfen
- Niederschlag -> Wasser fällt aus den Wolken
- Versickerung -> Wasser dringt in den Boden ein
:::

:::exercise
Kreise das richtige Wort ein.

1. Schnee ist Wasser in [[flüssiger | (fester)]] Form.
2. Pfützen trocknen an [[(sonnigen) | bewölkten]] Tagen schneller.
3. Das meiste Wasser auf der Erde ist [[Süßwasser | (Salzwasser)]].
:::

:::

:::solution
