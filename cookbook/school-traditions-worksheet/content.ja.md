# 水のたび {nombre="名前" fecha="日付"}

地球の水は、いつも動いています。太陽が海をあたためると、水は空にのぼり、雨や雪になってまたふってきます。この水のたびを、水のじゅんかんといいます。

:::exercise
正しいものをア〜ウからえらび、記号で答えましょう。

1. 雲からふってくる水を何といいますか。
   - [ ] 水じょう気
   - [x] 雨
   - [ ] きり
2. 太陽が海をあたためると、海の水はどうなりますか。
   - [x] じょう発する
   - [ ] こおる
   - [ ] しずむ
:::

:::exercise{type="truefalse"}
正しいものには○、まちがっているものには×を書きましょう。

- [x] 雲は、小さな水のつぶでできている。
- [ ] 氷は、寒くなるととける。
- [x] 川は、水を海へ運ぶ。
- [ ] 雨は海から来るので、しおからい。
:::

:::exercise{bank}
下のことばから選んで、文を完成させましょう。

::bank[氷 | 風]

太陽が[[海]]をあたためます。水は[[水じょう気]]になって、空へのぼります。高いところでひやされて、[[雲]]になります。そして、[[雨]]や雪になってふってきます。
:::

:::exercise
ことばと、その意味を線でむすびましょう。

- じょう発 -> 水が水じょう気になる
- ぎょう結 -> 水じょう気が水のつぶになる
- ふっとう -> 熱した水から、さかんにあわが出る
- しみこむ -> 水が土の中に入っていく
:::

:::exercise
正しいほうのことばを○でかこみましょう。

1. 雪は、[[えき体 | (固体)]]の水です。
2. 水たまりは、[[(晴れ) | くもり]]の日のほうが早くかわきます。
3. 地球の水の大部分は、[[真水 | (海水)]]です。
:::

:::exercise{type="arithmetic"}
学校の水そうには 864 L の水が入ります。4 つの学級で同じように分けると、1 学級は何 L になりますか。筆算でもとめ、たしかめもしましょう。

- 864 ÷ 4
- 216 × 4
:::

:::exercise{type="open" lines="5"}
水を大切に使うのはなぜですか。理由を二つ書きましょう。

:::solution
使える真水は少なく、水をきれいにして家まで運ぶのにエネルギーがかかるからです。
:::
