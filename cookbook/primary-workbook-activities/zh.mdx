## 成品一览

一本三年级科学活动练习册的第 5 单元，A4 开本：*Animals with backbones*（脊椎动物）。开篇把单元放在一条绿色色带里，下面是一幅池塘的画；接着是十一道活动题，每道题的题号在一个绿色圆块里，旁边是铅笔、对话气泡或两人合作的图标。题目有：着色虚线框里的词库，打 T 或 F 的句子，用线把动物连到所属的类别，在一句话和一段短文里圈出词语，给青蛙的成长阶段标序号，找词游戏，给动物分类，一道写在横线上的开放题，还有一道写在方格纸上。西班牙文版按西班牙学校的习惯排同一个单元，判断题用 V 和 F，连线题写作 *une con flechas*。三幅插图用扩散模型生成。

## 做法

### 1 · 在 Markdown 里写活动题，样式只定一次

<Excerpt region="answer" />

每道活动题是一个 `:::exercise` 围栏。学生读到的内容和正确答案都写在正文里：`[[hair]]` 是答案为 *hair* 的空，`- [x]` 是一句正确的陈述，`- Dolphin -> Mammal` 是一组连线，`[[pelo | (plumas)]]` 是一道选择题，正确的词放在括号里。样式只管外观，所以十一道题共用一个 `actividad`，另一个样式 `cuadricula` 用 `extends` 继承它，把横线换成方格纸。引擎给题目编号，用一个种子打乱连线题的右栏和排序题的各项，把每个空都做得和最长的答案一样宽，免得空的宽度泄露答案；英文版印 T 和 F，西班牙文版印 V 和 F，配置里一个字也不用写。

### 2 · 给活动题配图标

<Excerpt region="icons" />

`exerciseStyles[].icons` 里的一个图标指向书中的一张图片，`:::exercise{icon="oral pareja"}` 把这些图片按书写顺序放在题号后面，朗读时读出它们的 `alt`。这些图标是用代码画在单元色圆块上的平面符号，所以在 PDF 里依然清晰，也会随调色板变色。练习册还会在要动笔的题旁边印一支铅笔；说话和两人合作的图标标出最后一题，这道题没有书写区（`area="none"`）。

### 3 · 用色带和插图开启单元

<Excerpt region="opener" />

单元的一级标题根据自己的属性（`unidad="Unit 5" pic="charca"`）画出色带、单元编号的圆角块和标题，并在色带下面放一幅 176 × 75 mm 的插图。活动题里的图片用一种不带图注、也不编号的资源类型（`dibujo`），练习册里的图就是这样印的。正文照顾小读者：Atkinson Hyperlegible Next，字号 12 pt，行距 17 pt，不断词，左齐右不齐。

## 变化

### 为老师印出答案

同一份 Markdown 就能排出教师用书：所有空都填好，正确陈述的方框打上勾，正确的词用品红色圈出。

```diff
   exerciseStyles: [actividad, cuadricula],
+  exercises: { edition: 'teacher' },
```

### 用方块给活动题编号

换成单元色的圆角方块，看起来就是另一家出版社的版式。

```diff
-  number: { shape: 'disc', background: col('unit'), color: col('paper'),
+  number: { shape: 'rounded', background: col('unit'), color: col('paper'),
```

## 常见问题

- 在连续文字里要圈的词，两侧各留一点空隙给圆圈，所以紧挨在逗号或句号前的词会和标点稍稍分开。
