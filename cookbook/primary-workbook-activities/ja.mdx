## できあがり

小学3年生向け理科ワークの第5単元を A4 判で組みます。題は *Animals with backbones*（背骨のある動物）です。単元のとびらでは、緑の帯の下に池の絵を置きます。そのあとに11の活動が続き、どれも緑の円に入った番号と、えんぴつ、ふきだし、ペアのいずれかのアイコンを持ちます。点線で囲んだ色付きの枠の語群、T か F に印をつける文、動物をその仲間に線で結ぶ問題、一文と短い文章の中で丸で囲む語、番号をつけるカエルの成長段階、文字さがし、動物の仲間分け、罫線に書く自由記述の問い、方眼に書くもうひとつの問いが並びます。スペイン語版は同じ単元をスペインの学校の流儀で組み、V と F、*une con flechas* を使います。挿絵の3枚は拡散モデルで生成しました。

## 作り方

### 1 · 活動は Markdown に書き、スタイルは一度だけ決める

<Excerpt region="answer" />

活動はどれも `:::exercise` のブロックです。児童が読む文も正解も本文にあります。`[[hair]]` は答えが *hair* の空欄、`- [x]` は正しい文、`- Dolphin -> Mammal` は線で結ぶ組、`[[pelo | (plumas)]]` は正しい語をかっこに入れた選択肢です。スタイルが持つのは見た目だけなので、11の活動はひとつの `actividad` を共有し、2つ目の `cuadricula` が `extends` でそれを受け継いで、罫線を方眼に替えます。エンジンは活動に番号をふり、結ぶ問題の右の列と並べかえの項目をシードで混ぜ、どの空欄もいちばん長い答えの幅にそろえて答えが透けないようにします。英語版には T と F、スペイン語版には V と F を印刷し、設定にそのための語はひとつも書きません。

### 2 · 活動にアイコンを付ける

<Excerpt region="icons" />

`exerciseStyles[].icons` のアイコンは本の画像をひとつ指し、`:::exercise{icon="oral pareja"}` は書いた順に画像を番号のあとに並べます。読み上げでは `alt` が読まれます。アイコンは単元の色の円の上にコードで描いた平らな記号なので、PDF でもくっきりし、パレットに合わせて色が変わります。書く活動の横にはえんぴつを置きます。話すアイコンとペアのアイコンは最後の活動の印で、そこには書く欄がありません（`area="none"`）。

### 3 · 単元を帯と絵で始める

<Excerpt region="opener" />

単元のレベル1の見出しが、属性（`unidad="Unit 5" pic="charca"`）から帯、単元番号の角丸、題を描き、帯の下に 176 × 75 mm の絵を置きます。活動の中の絵には、キャプションも番号もないリソースの種類（`dibujo`）を使います。ワークの絵はそう印刷するものだからです。本文は子どもにも読みやすく組みます。Atkinson Hyperlegible Next の 12 pt、行送り 17 pt、ハイフネーションなし、左揃えです。

## アレンジ

### 先生用に答えを印刷する

同じ Markdown から先生用の版ができます。空欄はすべて埋まり、正しい文のボックスには印が付き、正しい語はマゼンタの丸で囲まれます。

```diff
   exerciseStyles: [actividad, cuadricula],
+  exercises: { edition: 'teacher' },
```

### 活動の番号を四角に入れる

単元の色の角丸の四角にすると、別の出版社の体裁に見えます。

```diff
-  number: { shape: 'disc', background: col('unit'), color: col('paper'),
+  number: { shape: 'rounded', background: col('unit'), color: col('paper'),
```

## よくあるつまずき

- 文章の中で丸で囲む語は、丸のために左右に少し余白を取ります。そのため、カンマやピリオドの直前にある語は、その記号から少し離れて見えます。
