## 成品一览

一本一年级写字练习册的十二页，A4 开本，共十个版本，也就是十本不同的书。每种语言用本国学校教的连笔字，取自 Google 的 Playwrite 字族（GB J、ES、FR Trad、DE VA、IT Trad、BR）或 Playpen Sans Arabic，写在那里的孩子平时用的纸上：西班牙的 *pauta*，带红色页边线的法国 Seyès 方格，中间有一条黄带的德国 *Lineatur*，巴西的 *caligrafia* 横线。中文版写在田字格里，孩子描浅红色的字（描红），拼音写在四线三格里；日文版写在带点线十字的マス格里，描灰色的字（なぞり書き）。课文跟着各自的拼写和书写规则走：西班牙语的 ñ 和不发音的 h，加泰罗尼亚语的 l·l，德语的 ß 和名词大写，中文的笔画和笔顺，日语的助词は、を、へ，阿拉伯语一个字母的四种形式和不与后一个字母相连的字母。每一行都从范字到点字，再到空白。二十九幅画用扩散模型生成，所有版本共用。

## 做法

### 1 · 给每个版本配上学校字体和格纸

<Excerpt region="editions" />

`u` 是以毫米计的 x 字高，每种书写格都以它为单位来画：大多数版本是 3.6 mm，法文版是 3 mm，因为 Seyès 的细线之间正好相隔一个 x 字高。Playwrite 各款的 x 字高都是字身的一半，所以范字的字号是 `u / 0.5`，书写格的线就落在字体自身比例给上伸部和下伸部定下的位置。中文正文用宋体（Noto Serif SC）：LXGW WenKai TC 按港台的印法把逗号放在字身正中，所以楷体只排标题和田字格。

### 2 · 范字用活的文字排在书写格上

<Excerpt region="answer" />

一个写字行就是一个标注框，要练的词就是框的内容：先写 `:::callout{type="palabra" title="Trace and write"}`，下一行单独写 `owl`，再写 `:::`（这是英文版的写法）。同一种形状的写字行共用一个框样式，彼此只差在词上。样式的 `design` 画一张图，即书写格和点字副本，再通过 `{boxText}` 用学校字体把这个词作为文字排在图上；`setsContent` 让标注框不在图下面把内容再排一遍。图片以这个词命名（`trazo-{boxText}`），pen 为它在标注框里找到的每个词各画一张。设计文字的基线落在文字框顶部以下 0.8 个行高处，所以范字的框放在这一行的基线减去 0.8 个行高的位置，字母就站在书写格画出的线上。行高是十个 x 字高，这样框的裁切边落在基线下方 2 u，g 的尾巴也放得下。标注框的标题就是这一行的标签。章节标题只用来构成书的大纲：封面是全书唯一的一级标题，每课是一个二级标题，封面样式的 `sectionEnd: 'heading'` 让封面的空白书眉到第一课为止。

### 3 · 用字体自己的轮廓画出点字

Postext 可以把字母排成彩色、空心或浅色，但不能把它画成沿笔画排列的一串点。这些点在排书之前就画好，取自每款 Playwrite 的 Thin 字重的轮廓：沿每条轮廓每隔 0.2 个 x 字高取一个点，只有在这个间距的 0.8 倍以内没有别的点时才保留，所以细笔画的两条边只留下一行点。i 上的点和重音符号仍是小小的实心形状。每个版本的点，连同副本和范字的步进宽度，都存在 `traces-<lang>.json` 里，再由 pen 把副本沿各行排开：第一行范字后排满副本，第二行整行都是点字，第三行范字后只跟一个副本，最后一行留空。

### 4 · 在格子里描字

<Excerpt region="squares" />

一个汉字或假名宽一个字身，所以把字距设为格宽减去字身，每格正好放一个字，和字帖一样。每行第一格是深色的字，后三格是同一个字的浅红描红字（日文版为灰色），其余格子空着。每个写字行的标注框把四个字写成列表项，设计用 `{boxText.1}` 到 `{boxText.4}` 依次读出。一个句子（`frase` 标注框）占三行：先写出来，再描，最后空着，标点也独占一格。拼音行用拉丁文各版的四线格，字体是 Andika，它的单层 a 和 g 正是孩子学的写法。

### 5 · 阿拉伯文版什么也不用镜像

阿拉伯文版和其他版本共用全部设计。排在从右到左页面文本流里的设计，不论属于标题还是标注框，都由引擎镜像，所以字母圆块、范字和字典的第一幅图都会移到右边；只有点字副本画在图片里面，要在代码里从右边缘排起，热身的波浪线也从右向左走。`locale: 'ar'` 让书在右边装订。

## 变化

### 改用美国的连笔字

Playwrite 为许多学校范本都做了字族。要用美国的连笔字，换掉英文版的字体，再重新生成它的点。

```diff
-  en: { hand: 'Playwrite GB J', ruling: 'gb', u: 3.6 },
+  en: { hand: 'Playwrite US Trad', ruling: 'gb', u: 3.6 },
```

### 隔一条 Seyès 粗线写一行

刚入学的孩子常常隔一条粗线写一行。把法文版各行的间距设为八条线。

```diff
-    seyes: { above: 4, below: 2, gap: -2, seyes: true }, // a row on every heavy line
+    seyes: { above: 4, below: 2, gap: 2, seyes: true },
```

## 常见问题

- 设计文字在自己的框边被裁掉。只有一行高的框会切掉范字里 g 和 p 的下伸部：给它很大的行高，再从基线出发定位。
- `loadCjkFonts` 为整个示例加载每一款字体：只要某款中文字体缺了文中任何地方用到的一个字，加载就会失败。版权页里的字体名要用拉丁字母写。
