## できあがり

A4判の小学1年生向け書き方練習帳を12ページ、10の版で組みます。10冊はそれぞれ別の本です。各言語には、その国の学校が教える続け字の書体を Google の Playwrite ファミリー（GB J、ES、FR Trad、DE VA、IT Trad、BR）か Playpen Sans Arabic から選び、その国の子どもが使う紙に置きます。スペインの *pauta*、赤い余白線の入ったフランスの Seyès 方眼、中央に黄色い帯があるドイツの *Lineatur*、ブラジルの *caligrafia* の罫線です。中国語版は田字格に書き、子どもは薄い赤の字をなぞり（描红）、ピンインは4本線に書きます。日本語版は教科書体に近い Klee One を、点線の十字が入ったマスに置き、灰色の字をなぞります（なぞり書き）。課の内容は各言語のつづりに沿っています。スペイン語の ñ と発音しない h、カタルーニャ語の l·l、ドイツ語の ß と名詞の大文字、日本語の助詞「は」「を」「へ」、アラビア語の文字の4つの形と、次の文字とつながらない文字。どの行も、お手本から点線へ、点線から空白へと進みます。拡散モデルで生成した29枚の絵は、すべての版で共通です。

## 作り方

### 1 · 各版に学校の書体と用紙を決める

<Excerpt region="editions" />

`u` はミリ単位のxハイトで、どの罫もこの単位で引きます。ほとんどの版は 3.6 mm、フランス語版は 3 mm です。Seyès の細い罫の間隔が、ちょうどxハイトひとつ分だからです。Playwrite の書体はどれもxハイトが全角の半分なので、お手本の大きさは `u / 0.5` になり、罫線は書体自身の比率がアセンダーとディセンダーを置く位置に来ます。中国語の本文は明朝体（Noto Serif SC）で組みます。LXGW WenKai TC は香港と台湾の印刷にならって読点を字面の中央に置くので、楷書体は題とマスにだけ使います。

### 2 · お手本はテキストのまま罫の上に置く

<Excerpt region="answer" />

練習の行は囲みで、練習することばがその中身です。英語版なら `:::callout{type="palabra" title="Trace and write"}` と書き、次の行に `owl` だけを置いて、`:::` で閉じます。同じ形の行はすべてひとつの囲みスタイルを共有し、違うのはことばだけです。スタイルの `design` が1枚の画像（罫と点線の写し）を描き、その上に `{boxText}` で学校の書体のことばを文字として組みます。`setsContent` があるので、囲みが絵の下に中身をもう一度組むことはありません。画像にはことばにちなんで `trazo-{boxText}` という名前を付け、pen は囲みの中に見つけたことばごとに1枚ずつ描きます。デザインのテキストは、ベースラインがボックスの上端から行の高さの0.8の位置に来ます。そこでお手本のボックスを行のベースラインから行の高さの0.8だけ上に置くと、文字は罫が引いた線の上に立ちます。行の高さはxハイトの10倍なので、ボックスの切り抜きはベースラインの 2 u 下に来て、g のしっぽまで入ります。囲みのタイトルが行のラベルになります。見出しは本のアウトラインのために使います。表紙が唯一のレベル1の見出しで、各課はレベル2の見出しです。表紙のスタイルの `sectionEnd: 'heading'` が、表紙の空の柱を最初の課で終わらせます。

### 3 · 点線を書体自身のアウトラインから描く

Postext は文字を色付き、袋文字、淡い色で組めますが、線に沿った点の列としては描けません。点は本を組む前に、各 Playwrite の Thin のアウトラインから描いておきます。輪郭に沿ってxハイトの0.2ごとに点を取り、その間隔の0.8以内にほかの点がないときだけ残すので、細い線の両側からは1列の点しかできません。i の点やアクセント記号は小さな塗りの形のまま残ります。各版の点は、写しとお手本の送り幅とともに `traces-<lang>.json` に入っていて、pen が写しを行に並べます。1行目はお手本のあとを写しで埋め、2行目は点線だけ、3行目はお手本に写しをひとつ添え、最後の行は空けておきます。

### 4 · マスの中の字をなぞる

<Excerpt region="squares" />

漢字や仮名の幅は全角ひとつなので、字間を「マスの幅 − 全角」にすると、字帖のように1マスに1字ずつ入ります。行の最初のマスにはお手本の字、続く3マスには同じ字を描红の薄い赤（日本語版は灰色）で置き、残りは空けておきます。行の囲みは4つの字をリストの項目として並べ、デザインが `{boxText.1}` から `{boxText.4}` で1字ずつ読みます。文（`frase` の囲み）は3行を使います。書いた行、なぞる行、空の行で、句読点もひとつのマスに入れます。中国語版のピンインの行は、ラテン文字の版と同じ4本線の罫に Andika で書きます。Andika の1階建ての a と g は、子どもが習う形です。

### 5 · アラビア語版では何も反転しない

アラビア語版は、ほかの版とすべてのデザインを共有します。右から左へ進むページの流れに置いたデザインは、見出しのものも囲みのものもエンジンが反転するので、文字を入れた円、お手本、絵辞典の最初の絵は右へ移ります。画像の中に描く点線の写しだけはコードで右端から並べ、準備運動の波線も右から左へ進めます。`locale: 'ar'` で本は右綴じになります。

## アレンジ

### アメリカの筆記体にする

Playwrite には多くの学校の手本に合わせたファミリーがあります。アメリカの筆記体にするなら、英語版の書体を替え、点線を作り直します。

```diff
-  en: { hand: 'Playwrite GB J', ruling: 'gb', u: 3.6 },
+  en: { hand: 'Playwrite US Trad', ruling: 'gb', u: 3.6 },
```

### Seyès の太い罫1本おきに書く

入学したばかりの子どもは、太い罫を1本おきに使って書くことがよくあります。フランス語版の行の間隔を罫8本分にします。

```diff
-    seyes: { above: 4, below: 2, gap: -2, seyes: true }, // a row on every heavy line
+    seyes: { above: 4, below: 2, gap: 2, seyes: true },
```

## よくあるつまずき

- デザインのテキストはボックスで切り抜かれます。1行分の高さのボックスでは、お手本の g や p のディセンダーが切れます。行の高さを大きく取り、ベースラインから位置を決めてください。
- `loadCjkFonts` はサンプル全体のためにすべての書体を読み込みます。本文のどこかで使う字が中国語の書体にひとつでも欠けていると、読み込みに失敗します。奥付の書体名はラテン文字で書きます。
