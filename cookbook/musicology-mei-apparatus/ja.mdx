## できあがり

イングランドの好古家たちが中世音楽をどう読んだかを扱う研究書の第3章です。判型156 × 234 mmの5ページで、レディングの輪唱曲 *Sumer is icumen in* と、1776年から1889年にかけてこれを総譜にした編者たちを論じます。輪唱曲の3か所を、Leipzigの書体と5 mmの譜表で本文中に刻み、小節番号はW. S. Rockstroの総譜に合わせています。各段落はページの下の校異を引きます。「b. 40, n. 2 A ] G Hw, Bu」。注は校異らしく短く詰まり、楽譜は本文の行長いっぱいに収まります。どの異読もGroveの『音楽・音楽家事典』にRockstroが書いた項目によるもので、章の第2段落でそのことを明記しています。

## 作り方

### 1 · 譜例をMEIで書き、異読も書き込む

設定は上の[手短な答え](#手短な答え)にあります。音楽はMarkdownの中に、譜例ごとに1つの ```` ```mei ```` ブロックで書きます。資料が食い違う箇所では、小節に `<app>` を置き、採った読みを `<lem>` に、もう一方を `<rdg source="#Hw #Bu">` に入れます。刻まれるのは `<lem>` なので、<PageRef page={5}>譜例3.3</PageRef>の第40小節にはAが印刷され、HawkinsとBurneyのGは符号化を開く人のためにファイルに残ります。各ブロックにはページの言語で `alt` を付けます。スクリーンリーダーとタグ付きPDFが楽譜について読み上げるのはこの文です。

### 2 · 校異を、読者に見える小節に結びつける

`barNumbers: 'system'` は各段の最初の小節に番号を付けます。各ブロックの `<measure n="37">` は、依拠した版でその部分が始まる番号から数え始めるので、譜例3.3は37から始まり、注の「b. 40」は読者が見つけられる小節を指します。校異の項目は普通の脚注で、その小節を論じる段落から引きます。採った読み、閉じ角括弧、異読、斜体の略号の順です。楽譜の中からは注を引けないので、合印はその読みを挙げる文に付けます。

### 3 · 本文に合う大きさで楽譜を組む

5 mmのLeipzigの譜表は116 mmの行長に、3/2拍子の小節を1段に5〜6小節入れて収まり、譜例3.3の11小節は2段になります。`textFont` は歌詞を本文の書体Crimson Proで組み、`minSystemsAtBreak: 2` は、譜例の1段だけをページの終わりに残して残りを次のページへ送ることを防ぎます。譜例の見出しは第3レベルの見出しなので、楽譜を伴わずにページの下に取り残されることはありません。

### 4 · 注のあるページは短く終わらせる

<Excerpt region="opener" />

章扉は本文をCormorantのイタリックの題の下、50 mmまで下げます。その先で、次の行が長い注を連れてくるページは数行早く終わります。`balancing: { maxLinesPerHeading: 1 }` は、段の均等化がその空きを次の節見出しの上へ移すのを防ぎます。そこに空きがあると、論の流れが切れたように見えるからです。

### 5 · 偶数ページに書名、奇数ページに章名

<Excerpt region="running-heads" />

ノンブルは朱色で外側に置き、偶数ページに書名、奇数ページに章名を入れます。`pages: 'body'` で章扉からは外し、章扉にはページ下の中央にノンブルを置きます。

## アレンジ

### すべての小節に番号を付ける

1段に校異の項目が多いときは、小節ごとに番号があるほうが追いやすくなります。

```diff
-  barNumbers: 'system', // the apparatus is keyed by bar: number every system
+  barNumbers: 'every',
```

### 譜例をBravuraで刻む

Bravuraの太めの符頭は、銅版彫刻風の社内様式によく合います。

```diff
-  musicFont: 'Leipzig', // lighter than Bravura, close to a 19th-century plate
+  musicFont: 'Bravura',
```

## よくあるつまずき

- MEI 5では調号を `scoreDef` か `staffDef` の `keysig="1f"` で書きます。MEI 4の属性 `key.sig` は知らせもなく無視され、フラットが消えます。
- どの `staffDef` にも `lines="5"` を付けます。これがないと、音符と音部記号は譜線のないところに刻まれます。
- 刻まれるのは `<app>` の `<lem>` で、`<rdg>` ではありません。ページ上で読者に見せたい異読は、校異の注か、もう1つの譜例に置きます。
