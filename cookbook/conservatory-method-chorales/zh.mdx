## 成品一览

《Four-Part Harmony》第4章，一本供音乐学院低年级使用的和声教程，开本210 × 280 mm，用Crimson Pro排成两栏。这一课讲终止式，五个谱例都是写在两行谱表上的四声部众赞歌，低音下方标出罗马数字级数：G大调的五种终止式、《Nun danket alle Gott》的三句，以及完整的日内瓦诗篇第134篇（*Old Hundredth*）。每个谱例都有编号，从Example 4.1到4.5（西班牙文版为Ejemplo），图注用标签字体，标签为酒红色，并排在引用它的段落之后那一栏的顶部或底部；整首诗篇横跨两栏，排在第63页顶部。这些和声配置是为本教程写的，并检查过平行五度和八度、声部间距以及导音的解决。

## 做法

### 1 · 用Humdrum **kern写每首众赞歌

<Excerpt region="humdrum" />

Humdrum把各声部写成用制表符分隔的列，从最低的声部写起。每行谱表是一列（*spine*），用`*^`一分为二：低音谱表上是男高音和男低音，高音谱表上是女高音和女低音，于是刻谱器在每行谱表上排两个声部，符干分开（左边的声部朝上，右边的朝下）。低音谱表之后的`**harm`列在它下方印出级数；`Ib`是第一转位，`Ic`是四六和弦。脚本用空格写各列，再把空格换成制表符，这样任何编辑器都弄不坏文件；西班牙文版的级数全用大写（VI、IIb），这是西班牙和声教材的写法。

### 2 · 把每个谱例做成example类型的资源

[简短回答](#简短回答)创建了这五个资源。`typeId: 'example'`使用内置的“谱例”类型：资源用到它时，引擎就把它加入书的资源类型，名称随文档语言而定（`locale: 'es'`得到Ejemplo），按章编号，所以第4章的第一个谱例是4.1。乐谱资源始终完整，像插图一样浮动：`position: 'top'`或`'bottom'`占据引用之后第一个有空间的栏的顶部或底部，`span: 'page'`让*Old Hundredth*横跨两栏。图注、出处和替代文本来自每个版本的第二个Markdown文件。

### 3 · 给栏内谱例更小的谱表

<Excerpt region="scores" />

两个通栏的众赞歌使用文档的`scoreStyle`：谱表高5.4 mm，每行开头标小节号。栏内谱例选用名为`column`的样式：谱表4.6 mm，不标小节号，间距0.8，使谱例4.2的五个小节留在同一行，而不是把最后一小节单独留到第二行。

### 4 · 排版前启动刻谱器

<Excerpt region="build" />

`initMusicEngine()`从软件包加载刻谱器Verovio；在它运行之前，每份乐谱都排成灰色方框。`continuation`让这一章成为一本更长的书的第4章，所以谱例编号为4.1到4.5，页码从右页的61开始。

### 5 · 让章首横跨两栏

<Excerpt region="opener" />

章首页横跨两栏（一级标题上的`span: 'page'`），眉题和导语取自标题的属性。`minHeight`让正文下沉46 mm，两栏都从短线下方的同一行开始。

## 变化

### 在正文中放一个不编号的谱例

用代码块写的乐谱留在正文里，正文并不引用它，像独立的公式一样：没有编号，也没有图注。

```diff
- ::resource{id="ex-cadences"}
+ ```humdrum {style="column" alt="G大调的五种终止式"}
+ **kern	**harm	**kern
+ …
+ ```
```

### 改称“音乐谱例”

为另一个名称定义自己的类型，并让`typeId`指向它。

```diff
- resourceTypes: defaultResourceTypes(LANG),
+ resourceTypes: [...defaultResourceTypes(LANG), { id: 'musex', name: '音乐谱例',
+   shortLabel: '谱例', captionPrefix: '音乐谱例', numberingTemplate: '{h1}.{n}',
+   resetOn: 'h1', counterFormat: 'decimal' }],
```

## 常见问题

- 乐谱资源从不在栏与栏、页与页之间断开。浮动谱例要限制在几个小节之内；较长的曲子放进代码块，它会在行与行之间断开。
- 刻谱器把每行谱填满到所在位置的宽度，最后一行保留自然宽度。如果某个谱例把一个小节单独留在第二行，就调低其样式的`spacing`或谱表大小。
