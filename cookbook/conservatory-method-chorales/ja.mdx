## できあがり

音楽学校の初年次向け和声教本『Four-Part Harmony』の第4章です。210 × 280 mmの判型に、Crimson Proで2段に組みます。課題は終止形で、5つの譜例はすべて2段の譜表に書いた4声のコラールです。バスの下にはローマ数字で度数を付けています。収めるのはト長調の5つの終止形、『Nun danket alle Gott』の3行、そしてジュネーヴ詩編第134編（*Old Hundredth*）の全曲です。各譜例にはExample 4.1から4.5（スペイン語版ではEjemplo）の番号が付き、ラベル用の書体のキャプションにワインレッドのラベルが付きます。譜例はそれを引用した段落のあとの段の天か地に置かれ、詩編の全曲は63ページの天に2段にまたがって組まれます。和声づけはこの教本のために書いたもので、平行5度・8度、声部間の間隔、導音の解決を確認しています。

## 作り方

### 1 · コラールをHumdrum **kernで書く

<Excerpt region="humdrum" />

Humdrumは声部をタブ区切りの列で書き、いちばん低い声部から並べます。各譜表は1つの列（*spine*）で、`*^`で2つに分けます。ヘ音記号の譜表にテノールとバス、ト音記号の譜表にソプラノとアルトを置くので、刻譜エンジンは1つの譜表に2声部を符尾を分けて書きます（左の声部が上向き、右の声部が下向き）。バスの譜表のあとの`**harm`列が、その下に度数を印刷します。`Ib`は第1転回形、`Ic`は四六の和音です。スクリプトは列をスペースで書いてタブに変えるので、どのエディターでもファイルが壊れません。スペイン語版では、スペインの和声教本の書き方にならって度数をすべて大文字（VI、IIb）にします。

### 2 · 譜例をexample型のリソースにする

[手短な答え](#手短な答え)が5つのリソースを作ります。`typeId: 'example'`は組み込みの「譜例」型を使います。リソースがこの型を使うと、エンジンが本のリソース型に加え、文書の言語で名前を付け（`locale: 'es'`ならEjemplo）、章ごとに番号を振ります。そのため第4章の最初の譜例は4.1になります。楽譜リソースは分割されず、図と同じように浮動します。`position: 'top'`または`'bottom'`は引用のあとで空きのある次の段の天か地を取り、`span: 'page'`は*Old Hundredth*を2段にまたがせます。キャプション、出典、代替テキストは、版ごとの2つ目のMarkdownファイルから読みます。

### 3 · 段に入れる譜例の譜表を小さくする

<Excerpt region="scores" />

ページ幅の2つのコラールは文書の`scoreStyle`に従い、譜表の高さは5.4 mm、各段の頭に小節番号が付きます。段に入れる譜例は名前付きスタイル`column`を選びます。譜表は4.6 mm、小節番号なし、間隔0.8で、譜例4.2の5小節を1段に収め、最後の1小節だけが2段目に残らないようにしています。

### 4 · 組版の前に刻譜エンジンを起動する

<Excerpt region="build" />

`initMusicEngine()`はパッケージから刻譜エンジンVerovioを読み込みます。起動するまで、楽譜はすべて灰色の箱として組まれます。`continuation`でこの章を長い本の第4章にしているので、譜例は4.1から4.5と番号が付き、ノンブルは奇数ページの61から始まります。

### 5 · 章扉を2段にまたがせる

<Excerpt region="opener" />

章扉は2段にまたがり（第1レベルの見出しに`span: 'page'`）、柱見出しとリードを見出しの属性から取ります。`minHeight`で本文を46 mm下げるので、2つの段は罫の下の同じ行から始まります。

## アレンジ

### 番号なしの譜例を本文に置く

コードブロックに書いた楽譜は、本文から引用されずにそのまま本文に置かれます。別行立ての数式と同じで、番号もキャプションも付きません。

```diff
- ::resource{id="ex-cadences"}
+ ```humdrum {style="column" alt="ト長調の5つの終止形"}
+ **kern	**harm	**kern
+ …
+ ```
```

### 「音楽譜例」と呼ぶ

別の名前にするには独自の型を定義し、`typeId`をそれに向けます。

```diff
- resourceTypes: defaultResourceTypes(LANG),
+ resourceTypes: [...defaultResourceTypes(LANG), { id: 'musex', name: '音楽譜例',
+   shortLabel: '譜例', captionPrefix: '音楽譜例', numberingTemplate: '{h1}.{n}',
+   resetOn: 'h1', counterFormat: 'decimal' }],
```

## よくあるつまずき

- 楽譜リソースは段やページをまたいで分割されません。浮動させる譜例は数小節にとどめ、長い曲はコードブロックに入れます。コードブロックなら段と段のあいだで分かれます。
- 刻譜エンジンは各段を置き場所の幅いっぱいに広げ、最後の段だけは自然な幅のままにします。譜例の1小節だけが2段目に残るときは、そのスタイルの`spacing`か譜表の大きさを下げます。
