## 成品一览

虚构的城市生活季刊《Patio》第 46 至 49 页。专题写一位退休的排字工：她在自己干了三十年的印刷厂楼顶养着十四箱蜜蜂。开篇跨页的左页是照片，标题压在楼顶的碎石上，天空里放一个浅色底的数字方框。右页是导语和前两栏，一段引语跨在栏间距上，旁边立着一只抠掉背景的草编蜂笼，第二栏的行顺着笼顶的弧线排。之后文章需要几页就占几页，每页三栏，排到哪里就在哪里结束。西班牙语、英语和德语版是同一个模板换了文字，德语的长复合词要穿过 60 毫米宽的栏。

## 做法

### 1 · 一个模板，一篇文章

代码就是上面的[简短回答](#简短回答)。整篇专题是一个 `::::page{template="apertura" spread}` 围栏：标题进入 `takes: 'h1'` 的框，数字和导语进入各自的槽位，其余没有指定槽位的内容都进入流文框 `col-1`。`col-1` 排满后，文字接着进入 `col-2`，按它的宽度重新断行；`col-2` 放不下的部分，在截断处印上 *Continúa* 之后，续排到跨页后面新增的一页（`overflow.continueIn: 'template:seguido-par'`）。文字既不指定栏，也不指定页：删掉一段，后面的每一行都往回移。

### 2 · 文章新增的页

<Excerpt region="pages-after" />

每个新增页有三个串接的栏，各宽 60.3 毫米。两个模板轮流接手文章，是因为续排的内容会落进与截断它的框同名的框：续排到自身的模板，每次只会重新填满它的第三栏。两页上的框名字不同，文章就从流文框重新开始，依次排满三栏。`KEEP` 关掉重排步骤里缩小文字和图片的那几步，否则它们会先于新增页被尝试：一篇多出五行的文章，最后一页会缩到 92.5% 排出。

### 3 · 两个推开栏文的框

<Excerpt region="push" />

这两个框都不属于文章，只推开它们压住的栏里的行。引语锚定在导语下方 82 毫米处，跨在栏间距上，所以第一栏让出右侧，第二栏让出左侧。蜂笼的框设了 `wrap: 'contour'`：它旁边的每一行，按图片在该行高度上的宽度再加 2.5 毫米间距缩短，于是第二栏顺着笼顶排，到笼底以下又恢复全宽。

### 4 · 跟着图片走的轮廓

<Excerpt region="pictures" />

排版只按尺寸读取图片，从不读像素，所以轮廓用 `traceResourceContour` 从 PNG 的 Alpha 通道里取一次，作为 `contour.traced` 跟着资源走。蜂笼是一张 720 像素、200 色、透明底的 PNG（225 KB）。左页的照片是装饰图片 `resourceId: '{attr.foto}'`：用哪张照片由围栏决定，放在哪里由模板决定。

### 5 · 从围栏读取的书眉

<Excerpt region="running-heads" />

开篇跨页不印书眉（`header: false`）；新增的页在左页印杂志名，在右页印栏目名。栏目名来自围栏上的 `seccion="Ciudad"`，`{attr.seccion}` 在文章新增的页上读到的值和在跨页上一样。

## 变化

### 按矩形绕排蜂笼

去掉 `wrap: 'contour'`，框就按它的矩形推开文字，笼顶旁边的行停在一条直边上。

```diff
-  { name: 'recorte', exclude: 'push', wrap: 'contour', layer: 2, width: mm(58),
+  { name: 'recorte', exclude: 'push', layer: 2, width: mm(58),
```

### 去掉续排标记

设 `mark: false`，截断的片段排到最后一行就结束，不印 *Continúa*，这一栏能多放一行。

```diff
-      overflow: { continueIn: 'template:seguido-par' } },
+      overflow: { continueIn: 'template:seguido-par', mark: false } },
```
