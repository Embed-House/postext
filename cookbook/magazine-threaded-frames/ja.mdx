## できあがり

架空の都市生活季刊誌『Patio』の46〜49ページ。三十年勤めた印刷所の屋上で十四箱の蜜蜂を飼う、引退した植字工の特集です。巻頭見開きの左ページは写真で、見出しは屋上の砂利の上に、数字を並べた色付きの囲みは空に置きます。右ページにはリードと最初の二段。段間には引用がまたがり、背景を切り抜いた麦わらの巣箱が立っていて、二段目の行はそのドームの形に沿って組まれます。そのあと記事は必要なだけページを使い、一ページ三段で、終わるところで終わります。スペイン語、英語、ドイツ語の版は同じテンプレートに別の言葉を入れたもので、ドイツ語は長い複合語を60mmの段に通します。

## 作り方

### 1 · 一つのテンプレートに一つの記事

コードは上の[手短な答え](#手短な答え)にあります。特集全体が一つの `::::page{template="apertura" spread}` フェンスです。見出しは `takes: 'h1'` の枠へ、数字とリードはそれぞれのスロットへ、スロットを指定しないそれ以外の内容はすべて流し込み枠 `col-1` へ入ります。`col-1` がいっぱいになると文章は `col-2` に続き、その幅で改めて行分けされます。`col-2` に収まらない分は、切れたところに *Continúa* の文字を置いてから、見開きの後ろに追加されるページへ続きます（`overflow.continueIn: 'template:seguido'`）。文章は段もページも指定しません。段落を一つ削れば、後ろの行がすべて前へ戻ります。

### 2 · 記事が追加するページ

<Excerpt region="pages-after" />

追加ページはどれも、幅60.3mmの段を三つつないだもので、テンプレートはすべてのページで一つです。三段目は同じテンプレートへ続き、記事は連鎖の先頭の枠 `seguido-1` から再開します。何ページ要っても、各ページで三段すべてが埋まります。文字サイズを固定する設定も要りません。別のページへ続ける枠は、文字を縮める前に続きへ送るので、五行あふれた記事は最後のページで92.5%に縮むのではなく、新しいページを得ます。

### 3 · 段を押しのける二つの枠

<Excerpt region="push" />

どちらの枠も記事の一部ではなく、重なった段の行を押しのけるだけです。引用はリードから82mm下に固定されて段間にまたがるので、一段目は右側を、二段目は左側を削られます。巣箱の枠には `wrap: 'contour'` が付いています。その横の行は、その高さでの絵の幅に2.5mmの間隔を足した分だけ短く組まれるので、二段目はドームに沿って流れ、底より下ではまた全幅に戻ります。

### 4 · 画像といっしょに運ばれる輪郭

<Excerpt region="pictures" />

レイアウトは画像を大きさで読み、ピクセルは読みません。そのため輪郭は `traceResourceContour` でPNGのアルファチャンネルから一度だけ取り出し、`contour.traced` としてリソースに持たせます。巣箱は720px、200色、背景透明のPNG（225KB）です。左ページの写真は飾りの画像 `resourceId: '{attr.foto}'` で、どの写真にするかはフェンスが、どこに置くかはテンプレートが決めます。 `fit: 'cover'` を付けてあるので、写真の縦横比にかかわらず左ページを埋め、枠からはみ出した部分は切り取られます。

### 5 · フェンスから読む柱

<Excerpt region="running-heads" />

巻頭の見開きには柱を出しません（`header: false`）。追加ページでは左ページに誌名、右ページにセクション名が入ります。セクション名はフェンスの `seccion="Ciudad"` から来ていて、`{attr.seccion}` は記事が追加したページでも見開きと同じ値を読みます。

## アレンジ

### 巣箱を矩形で回り込ませる

`wrap: 'contour'` を外すと枠は矩形で押しのけ、ドームの横の行はまっすぐな縁で止まります。

```diff
-  { name: 'recorte', exclude: 'push', wrap: 'contour', layer: 2, width: mm(58),
+  { name: 'recorte', exclude: 'push', layer: 2, width: mm(58),
```

### 継続マーカーを外す

`mark: false` にすると、切れた部分は *Continúa* を置かずに最後の行で終わり、その段に一行多く入ります。

```diff
-      overflow: { continueIn: 'template:seguido' } },
+      overflow: { continueIn: 'template:seguido', mark: false } },
```

## よくあるつまずき

- テンプレートが独立した枠へ送る見出しは、テキストの枠ではドロップキャップを開きません。特集の最初の段落は `:::paragraphs{style="inicio"}` で包み、`dropCap` はそのスタイルに持たせます。
