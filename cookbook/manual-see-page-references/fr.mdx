## Ce que vous allez composer

Le manuel d’utilisation d’un vélo de randonnée imaginaire, l’Ardena T3 : quatre pages A5 composées en Archivo, avec le nom du modèle dans un bandeau bleu marine sur la première page. Un manuel se lit dans le désordre : chaque consigne qui dépend d’une autre indique donc où elle se trouve, *see section 3.2 on page 3*. Le rédacteur désigne un titre, un paragraphe ou un passage d’une étape avec un identifiant et écrit `:ref` partout où le texte y renvoie ; Postext imprime le numéro, le titre ou la page et en fait un lien. La table des matières de la couverture s’écrit de la même façon : déplacer une section, ou traduire le manuel et le laisser se recomposer, ne laisse jamais un numéro périmé.

## Préparation

### 1 · Nommer ce vers quoi le texte renvoie

Le code se trouve dans [la réponse courte](#la-réponse-courte) plus haut. Les titres prennent un identifiant Pandoc, `### Checking pad wear {#sec-pad-wear}` ; l’avertissement sur la pression des pneus commence par `:anchor{#warn-pressure}`, une marque invisible ; la dernière étape du montage d’une roue est `[close the lever so that it points backwards]{#step-close-lever}`, qui garde ses mots et leur donne un nom ; et l’encadré s’ouvre par `:::callout{#box-wet type="note" title="Wet weather"}`. Un renvoi à l’étape imprime les mots de l’étape, un renvoi à l’encadré son titre.

### 2 · Une cible, quatre façons de la nommer

`:ref{id="sec-pad-wear"}` imprime *section 3.2* avec le mot de `crossRefs.section` ; `style=page` imprime *page 3* avec le mot de `crossRefs.page` ; `style=title` imprime *Checking pad wear* ; `style=pageNumber` imprime le *3* seul. La table des matières de la couverture combine le numéro seul, le titre et la page seule, et se lit donc comme une table des matières. En espagnol, les mêmes renvois impriment *apartado 3.2* et *página 3*, car les modèles suivent la langue de l’édition.

### 3 · Les pages se fixent d’elles-mêmes

Un numéro de page n’est connu qu’une fois le manuel mis en page. Le moteur le met en page, relève la page où chaque cible est tombée et recommence jusqu’à ce qu’aucun renvoi ne change : c’est la même boucle que celle qui remplit une table des matières. Un texte qui s’allonge à la traduction, ou une section déplacée vers le début, change les pages, et les renvois les suivent, en avant comme en arrière.

### 4 · Les numéros viennent du compteur de niveau 2

<Excerpt region="numbers" />

Le manuel n’a qu’un titre de niveau 1, le nom du modèle sur la couverture : ses sections sont donc numérotées à partir du niveau 2. `{2}` donne 1 à 5 et `{2}.{3}` donne 1.1, 1.2.

### 5 · La couverture est l’ouverture de ce titre

<Excerpt region="cover" />

Le bandeau fait 104 mm de haut, la moitié de la page, et une bande orange le ferme. Le surtitre, le sous-titre et la ligne d’édition sont des attributs du titre : l’édition espagnole les change donc dans son propre texte.

## Variantes

### Écrire « p. » dans les renvois

Un ouvrage de référence riche en renvois de page gagne de la place avec l’abréviation.

```diff
-  page: t({ en: 'page {n}', es: 'página {n}' }), // spelt out: a manual is read by anyone
+  page: t({ en: 'p. {n}', es: 'pág. {n}' }),
```

### Laisser les renvois à l’encre

Quand la page est faite surtout de renvois, gardez-les dans la couleur du texte et en gras ; ils restent des liens dans le PDF et à l’écran.

```diff
-const references = { referenceColor: col('orange'), referenceBold: true };
+const references = { referenceColor: col('ink'), referenceBold: true };
```

## Erreurs fréquentes

- Un renvoi sans style vers un `:anchor` imprime la page, car une ancre invisible n’a pas de mots à elle. Utilisez `[words]{#id}` quand le renvoi doit citer le texte.
- Un identifiant doit être unique dans le livre. Les renvois atteignent le premier `{#sec-brakes}`, et le panneau Vérifications du Sandbox signale le second comme `duplicateAnchor`.
