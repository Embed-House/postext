## 成品一览

《Water on the move》是一本虚构的四年级科学练习册的第 3 单元，这里排了其中五页，开本 210 × 280 mm。封面上平涂的水循环插图一直画到出血位，下面是 54 pt 的标题和一条写名字的横线。每张练习页都出自同一个页面模板：单元名、蓝色标题带、配插图的短文，以及三个带编号标签的浅蓝色活动框。第一个和第三个框下面是写答案的横线。每个框的高度跟着自己的文字走，所以法文版的练习页这里那里多出一行，横线就比英文版排得更低，而模板里没有任何位置改变。手工项目是用瓶子做一个雨量计，步骤多到一页放不下：步骤框在页脚处带着 *Continued* 截断，接到新增一页的顶部，后面再跟六条写观察记录的横线。所有文字，包括标签和观察记录的标题，都写在 Markdown 里。

## 做法

### 1 · 按名称把每个活动倒进自己的框

模板就是上面的[简短回答](#简短回答)。在 Markdown 里，每张练习页是一个 `::::page` 围栏：第一个标题进入带 `takes: 'h1'` 的框，段落进入流式框，每个 `:::frame{slot="…"}` 进入同名的框，标签上的文字写在 `label` 里。答题框什么也不接收，所以标了 `optional: true`，否则空框会触发 `slotEmpty` 警告。画画的活动用 `:::space{lines=3}` 在自己的框里留出空白，因为画画要多大地方，本身就是题目的一部分。

```md
:::frame{slot="act-1" label="1 · Read and answer"}
Tom lives in Leeds. The water from his tap comes from a reservoir in the hills…
:::
```

### 2 · 让堆叠组带着横线和框一起移动

每个框的 `minHeight` 是 22 mm，也就是它画出来的高度，超过这个高度就是 `auto`。组从 `act-1` 被放在正文下方的位置开始，把五个框一个接一个往下排，间隔 4.5 mm，所以一个框变高，后面的一切都会往下移。横线是装饰里的线条，锚定在各自的空框上（`#lineas-1`），跟随框的装饰会随框移动。给答题框设一个等于其高度的 `minHeight`：组里地方不够时，[重排阶梯](/zh/docs/composed-pages#仍然放不下时)会从组内各框收回空间，直到它们的最小值，而空框的最小值是零，横线就会压到下一个框上。

### 3 · 把项目接到下一页

<Excerpt region="continue" />

步骤框没有固定高度：它随文字变高，最多到版心底部为止。`fit: { shrinkText: false }` 不让阶梯把步骤缩到 90 % 硬塞进去，所以框以原字号在两行之间截断，末尾加上该语言的续排标记（*Continúa*、*Continued*、*À suivre*，由 `locale` 决定），再接到 `proyecto-sigue` 模板一页里的同名框（[文字续排时](/zh/docs/composed-pages#文字续排时)）。新增的一页在框的剩余部分下面画出观察记录的横线，标题来自围栏里的 `notas="What I noticed"`，这样文字仍在 Markdown 里，随每个版本变化。

### 4 · 封面画到出血位

<Excerpt region="cover" />

封面也是模板页：插图是锚定在出血位上的装饰，标题、丛书名和名字栏组成一个堆叠组，从版心顶部往下 162 mm 处开始。名字栏的线锚定在框底，所以换一种语言后标签占两行，线仍然在文字下面。`header: false` 和 `footer: false` 让封面不印页码。

## 变化

### 给一个活动多几条横线

横线的数量就是答题框的高度加上画在上面的线。在模板里把两者都改了，用这个模板的每张练习页都会有这些横线。

```diff
-    answer('lineas-1', 3),
+    answer('lineas-1', 5),
…
-  decoration: { elements: [kicker, ...ruled('lineas-1', 3), ...ruled('lineas-3', 2)] },
+  decoration: { elements: [kicker, ...ruled('lineas-1', 5), ...ruled('lineas-3', 2)] },
```

### 续排之前先让步骤缩小

去掉 `shrinkText: false` 后，阶梯会先把步骤缩小，最多到 `fit.minScale`（90 %），仍不够时才移到另一页。给孩子看的书，字号比省一页更要紧。

```diff
-      fit: { shrinkText: false, scaleImages: false }, overflow: { continueIn: 'next-page' } },
+      overflow: { continueIn: 'next-page' } },
```

## 常见问题

- 什么都不接收的框，没有 `optional: true` 就会触发 `slotEmpty`。这里每个答题框都标了。
- 在堆叠组里，框由组来摆放，不看它自己的 `placement`，第一个框除外：要给组里的第一个框定位，否则整组会从版心顶部开始，压在标题上。
