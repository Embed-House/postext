## できあがり

中学校の歴史の教科書の48・49ページ、「紙がたどった道」です。蔡倫の工房からケラーの砥石まで、紙すきの千年をたどります。左ページは題名と二つの段落で始まり、右ページは手すき紙の作り方を説明する囲みで始まります。真ん中を年表が横切ります。アジアは藍色の帯、ヨーロッパは赤茶の帯で、赤茶の帯は左ページから始まってのどをまたぎます。その下に、絵の付いたカードが六枚、点と線で帯からつり下がっています。カードは幅を分け合います。いちばん話の長い1844年のカードが両隣から幅を借り（スペイン語版で3mm、日本語版で13mm）、その点もいっしょに動きます。文字はすべてMarkdownにあり、スペイン語、英語、日本語の三版があります。このページは日本語版です。

## 作り方

### 1 · 二ページで一枚のシート

<Excerpt region="answer" />

`spread: true`でテンプレートは二ページ分の幅の一枚のシートになり、ページのブロックも`spread`で同じことを示します。見開きは左ページから始まるので、ビルドに`continuation: { pageIndexOffset: 1, pageNumbering: { startAt: 48 } }`を渡します。この抜粋の1ページ目は本の48ページ、左ページになり、前に白ページは入りません。グリッドは一ページに一列で、列の間はノド側の余白の二倍です。のどに近づくのは帯だけです。二本目の帯は`crossGutter`と左の36mmの余白を持ちます。色は一本目の帯の端から続いてのどをまたぎ、文字は右ページから始まります。文字が読まれるのも右ページです。

### 2 · 幅を分け合うカード

<Excerpt region="cards" />

三枚のカードの列はそれぞれ`row`グループで、カードには固定の高さ（`height`）と、それより16mm高い`maxHeight`があります。カードの文章が高さに収まらないと、`shrink`を持つ隣のカードから必要な最小のミリ数を借ります。隣のカードは、自分の文章が収まる幅を残します。借りきれないときにだけカードは下へ伸び、`maxHeight`まで大きくなります。日本語版では1844年のカードが13mm借ります。すべての文章を30%長くしたベンチのテストでは、1150年と1282年のカードの絵も92.5%に縮み、囲みとリードの文字は87.5%と82.5%になります。

### 3 · カードに付いて動く点

<Excerpt region="marks" />

点と線はテンプレートの飾り（`decoration`）で、`#c1` … `#c6`の上端（`top`）に固定し、帯までの距離だけ上にずらしています。飾りは枠を置いたあとに配置されるので、カードが動いたり広がったりしても、点はいつもカードの中央の上にあります。クリーム色の地も飾りで、裁ち落としの下端に固定し、帯から始まる箱です。

### 4 · 印刷の大きさで置く絵

<Excerpt region="art" />

挿絵は幅1,000px、550ppiで、ページ上では46mmです。画像は拡大されないので、広がったカードは絵の大きさを保ち、増えた幅を文章に回します。46mmより狭いカードでは絵が縮みます。1844年のカードに幅を譲った1150年と1282年のカードがそうです。

## アレンジ

### カードの幅をそろえる

`shrink: 0`にすると、どのカードも幅を譲りません。1844年のカードは代わりに下へ伸び、`maxHeight`まで大きくなるので、列の下端がそろわなくなります。

```diff
-  shrink: 1, // a card gives width to a neighbour whose text runs past the row
+  shrink: 0,
```

## よくあるつまずき

- 高さが`'auto'`のカードを並べた列は幅を分け合いません。下の説明を読み、カードに高さを与えてください。
- 日本語版は、日本の歴史の教科書と同じく横組みです。縦組み（`vertical-rl`）の本で見開きのテンプレートを使うと、回転した本文の座標系に置かれ、枠も絵も地も位置がずれ、警告も出ません。いまのところ、テンプレートによる見開きは横組みの本で使ってください。
