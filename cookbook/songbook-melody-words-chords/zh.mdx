## 成品一览

《Songs for the Long Table》是一本A5开本的口袋歌本：茜红色的书名页，一篇写给唱歌的人的说明（附目录），三首歌，以及每首歌出处的注释。每首歌开头是一个茜红色的大号编号、用Fraunces排的歌名和一行小型大写字母排的署名。下面是旋律，用Leland排在5.5 mm的谱表上，吉他和弦标在小节上方，第一段歌词用本书的正文字体Spectral排在音符下。其余几段歌词分两栏排，唱的人从最后一小节直接往下读。《Amazing Grace》的诗行很长，放进一栏会转行，所以它的几段歌词一段接一段居中排列。西班牙语版是一本生日歌本，收三首较短的歌，每页两首。

## 做法

### 1 · 写下歌曲，乐谱样式只设一次

乐谱样式就是上面的[简短回答](#简短回答)。在Markdown中，每首歌是一个```` ```abc ````代码块：头部几行给出拍号、音符时值和调号；双引号里的和弦名（`"D7"A`）印在紧跟其后的那个音符上方；音乐下面的`w:`行在每个音符下放一个音节，音节之间用连字符分开。有主歌和副歌的曲子写成两行音乐，每行各有自己的`w:`行。谱表大小、音乐字体、歌词字体、小节编号和谱行间距都来自`scoreStyle`，所以三首歌外观一致，代码块里只有音乐。

### 2 · 每首歌以编号和署名开头

<Excerpt region="song-head" />

歌曲是一个带`credit`属性的一级标题，它的设计据此排出编号、歌名和署名行。`minHeight`让每首歌的标题区都高21 mm，所以每一页的谱表都从同样的深度开始。歌曲接排，每个歌名上方空三行；乐谱绝不在第二行谱之前断开（`minSystemsAtBreak: 2`）：英文版的歌一首占一页，西班牙语版的两首短歌合占一页。

### 3 · 其余几段歌词分两栏排

<Excerpt region="verse" />

每段歌词是一个`:::verse`块，所以诗行在诗人断行的地方断开，第二行和第四行缩进1 em。一个`:::columns{count=2 gap=4mm}`组把它们以9.4 pt并排。先数一数字符：Burns的诗行放得进55 mm宽的栏，Newton的长格律（long metre）放不进，所以《Amazing Grace》保留一个居中的`:::verse`块，用空行分隔各段。

### 4 · 书眉和页码保持低调

<Excerpt region="heads" />

歌曲排到的每一页都有书眉，左页印书名，右页印歌名，页码用与歌曲编号相同的茜红色。书名页和写给唱歌的人的说明在各自的标题样式中设一个空的`header`，去掉书眉。

## 变化

### 用Bravura刻谱

Bravura的符头更粗，有铜版刻印乐谱的样子，适合用颜色较深的正文字体排的赞美诗集。

```diff
-  musicFont: 'Leland', // lighter noteheads than Bravura, close to Spectral's colour
+  musicFont: 'Bravura',
```

### 给小节编号

合唱团排练时按小节号找位置：在每行谱的开头印一个小节号。

```diff
-  barNumbers: 'none', // a table of singers counts verses, not bars
+  barNumbers: 'system',
```

## 常见问题

- Verovio的ABC读取器忽略`w:`行中的`_`和`*`这两个占位记号：每个音符都取下一个音节。在圆滑线的第二个音符下，单独写一个不换行空格（U+00A0）作为一个音节，它什么也不印。用延音线连起的音符不取音节。
- `~`把两个音节合到一个音符下（`de~a-trás`），但刻谱引擎用普通空格把它们印出来，不印连接弧。
- 和弦名尽量不用♭或♯：大多数正文字体没有这些符号，页面会改用系统字体。选和弦都是本位音的调（G、C、D7、Em），或者在正文中写成“降B”。
