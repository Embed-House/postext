## できあがり

架空の小学4年生向け理科ワークブック『Water on the move』の単元3から5ページを、210 × 280 mm で組みます。表紙は水の循環を描いたベタ塗りの絵が裁ち落としまで広がり、その下に 54 pt の書名と名前を書く罫線があります。プリントはどれも同じページテンプレートから組みます。単元名の行、青い帯の見出し、絵を添えた短い本文、番号のタブが付いた水色の活動の囲みが三つ。一つめと三つめの囲みの下には答えを書く罫線があります。囲みの高さは中の文章で決まるので、あちこちで1行ずつ長くなるフランス語版では、テンプレートの位置を何も変えなくても英語版より罫線が下に来ます。工作はペットボトルで雨量計を作るもので、手順が1ページに収まりません。手順の囲みはページの下端で *Continued* を付けて切れ、追加されたページの上で続き、そのあとに観察を書く6本の罫線が続きます。タブや観察欄の見出しを含め、文字はすべて Markdown に書きます。

## 作り方

### 1 · 活動を名前で自分の囲みに流し込む

テンプレートは上の[手短な答え](#手短な答え)です。Markdown では、プリント1枚が一つの `::::page` フェンスです。最初の見出しは `takes: 'h1'` のフレームへ、段落はフローのフレームへ、`:::frame{slot="…"}` はそれぞれ同じ名前のフレームへ入り、タブの文字は `label` に書きます。解答のフレームには何も入らないので `optional: true` を付けます。付けないと空のフレームが `slotEmpty` の警告を出します。絵を描く活動は `:::space{lines=3}` で自分の囲みの中に白い場所を取ります。どれだけの場所が要るかは、問題の一部だからです。

```md
:::frame{slot="act-1" label="1 · Read and answer"}
Tom lives in Leeds. The water from his tap comes from a reservoir in the hills…
:::
```

### 2 · 罫線を囲みと一緒にスタックで動かす

囲みにはどれも描いたときの高さ 22 mm を `minHeight` に指定し、それより上は `auto` の高さにします。グループは、本文の下に置いた `act-1` の位置から5つのフレームを 4.5 mm 間隔で縦に並べるので、ある囲みが伸びるとその後ろがすべて下がります。罫線は空のフレームそのものに属します。その `rules` が、フレームの高さ 8 mm ごとの下端、文字の下に1本ずつ線を引くので、罫線はフレームと一緒に動き、解答欄を長くすればフレームが高くなります。解答のフレームには高さと同じ `minHeight` を指定してください。グループの場所が足りなくなると、[リフローの段階](/ja/docs/composed-pages#それでも収まらないとき)はグループのフレームから最小値まで場所を取り戻しますが、空のフレームの最小値はゼロなので、罫線が次の囲みに重なってしまいます。ワークシートの最後の囲み `act-3` は、文章がページに収まらないと次のページへ続き（`overflow.continueIn: 'next-page'`）、その下の解答の罫線も一緒に移ります。

### 3 · 工作を次のページへ続ける

<Excerpt region="continue" />

手順の囲みには決まった高さがなく、文章に合わせて伸び、版面の下端で止まります。別のページへ続けられるフレームは、文字を縮める前に続きへ送ります。そのため囲みは本来の文字サイズのまま行と行のあいだで切れ、言語ごとの続きの印（`locale` に応じて *Continúa*、*Continued*、*À suivre*）で終わり、`proyecto-sigue` のページの同じ名前のフレームで続きます（[文章が追加ページに続くとき](/ja/docs/composed-pages#文章が追加ページに続くとき)）。追加されたページは囲みの続きの下に観察の罫線を引き、見出しにはフェンスの `notas="What I noticed"` の文字を使います。文字は Markdown に残り、版ごとに変わります。

### 4 · 表紙を裁ち落としまで描く

<Excerpt region="cover" />

表紙もテンプレートページです。絵は裁ち落としに固定した装飾で、書名、シリーズ名、名前欄が版面の上から 162 mm の位置で始まるスタックになります。名前の罫はフレームの下端に固定してあるので、別の言語でラベルが2行になっても罫は文字の下にあります。`header: false` と `footer: false` で表紙にはノンブルを付けません。

## アレンジ

### 活動の罫線を増やす

罫線の本数は解答のフレームの高さで決まります。`rules` が入るだけの線を引くので、テンプレートでこの値を変えれば、それを使うすべてのワークシートにその本数の罫線が付きます。

```diff
-    answer('lineas-1', 3),
+    answer('lineas-1', 5),
```

### 続ける前に手順を縮めてみる

別のページへ続けられるフレームは、文字を縮める前に続きへ送ります。`fit.preferContinue: false` を指定すると、段階はまず手順を `fit.minScale`（90 %）まで小さく組み、それでも足りないときだけ別のページへ送ります。子どもの本では、1ページ減らすことより文字の大きさのほうが大事なので、このレシピは既定のままにしています。

```diff
-      overflow: { continueIn: 'next-page' } },
+      fit: { preferContinue: false }, overflow: { continueIn: 'next-page' } },
```

## よくあるつまずき

- 何も入らないフレームは、`optional: true` を付けないと `slotEmpty` を出します。ここでは解答のフレームすべてに付けています。
- スタックでは囲みを置くのはグループで、囲み自身の `placement` は使われません。ただし最初の一つは例外です。グループの最初の囲みの位置を決めておかないと、スタックは版面の上端から始まり、見出しに重なります。
